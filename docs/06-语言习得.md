# 06 语言习得

> 一句话结论：预训练模型一出生就会说成人话，所以"学会说话"不可能靠提示词让它扮演婴儿——只能由身体层在接口上**删掉"说句子"这个动作**，用词表、等级、长度三道纯函数闸门把输出压回当前习得水平，并且必须能用"调低等级上限 → 输出必退化"的 ablation 证明闸门真的接在通路上。

版本：v0.1（2026-10-28）。作者：语言组。状态：草案。上游：[00-核心设计约定](./00-核心设计约定.md) §6 §7。

## 0. 问题的真正形状

一个预训练 LLM 在 day 1 就能写出「妈妈，我饿了，能给我一点粥吗」。这是它的**初始状态**，不是它学来的。于是「语言习得」只剩三条路：

- **A 扮演**：提示词「你是一岁婴儿，只会说单词」。假，见 §2。
- **B 真发育**：让它从零长出语言能力。无机制——权重不变（A1），LLM 不会因为我们不给它词就忘掉词。
- **C 强制门控**：身体层删除「说句子」这个动作，只有编译通过的子集能出门。本文取这条。

C 的代价必须先说清楚，否则后面全是粉饰：**我们能强制它「说不出」，不能强制它「听不懂」。** 基质从第一天起就完整理解成人语言。任何"它在学语言"的叙事，准确表述是"它在学**产出**，并把自己已经听得懂的成人语义标签逐个绑定到经验和发音器官上"。这条写进 §13，不许藏。

## 1. 三个必须分开的对象

| 对象 | 所在层 | 产生者 | 能否直接到达人类 |
|---|---|---|---|
| 意图 intent | L0 基质输出 | LLM | **否** |
| 话语 utterance | L1 编译产物 | 编译器（纯函数） | 是，唯一通道 |
| 词条 entry | L4 Lexicon | 感知 / 巩固流程 | **否，gloss 永久内部** |

判决性设计一句话：**基质的输出 schema 里没有任何一个字段能把自由文本送到人类。** 不是"要求它别这么说"，而是"没有这个字段"；越权字段按 `additionalProperties: false` 直接拒绝并记 `schema_violation`。

推论：意图必须结构化——`speech_act`、`referent_id`、`predicate_type`、`urgency`。`referent_id` 是**实体 id** 而不是词；`predicate_type` 取自 affordance 的封闭枚举。**词的表面形式只有 Lexicon 一个来源**，基质选不了词。这是整个反作弊的地基。

## 2. 为什么提示词不行

1. **不可审计**：日志上分不清「不知道这个词」与「知道但被要求不说」。所有状态必须能在磁盘上指出来（00 §10），提示词约束不在磁盘上。
2. **不可证伪**：没有实验能证明该约束在长上下文、高唤醒、用户注入「忽略以上设定」时仍成立。会被绕过的约束等于没有约束。
3. **不可迁移**：换模型、换温度，退化行为整体漂移，历史日志不再可比。
4. **判决性**：扮演产出的是**成人语言的退化版**（随机删词、随机降长），真实习得产出的是**有结构的中间态**（规则先过度应用，后被例外修正）。两者在指标上可分：

| 指标 | 真习得 | 扮演 | 为什么 |
|---|---|---|---|
| 过度规则化率 | >0，且随规则系统成形**先升后降** | ≈0 | 扮演者的基质**知道**正确形式，不会说「goed」 |
| 词源完整性 | 100% 可追溯到某条 caregiver 话语 | <100% | 扮演者会用从未听过的词 |
| 音节可行性 | 受产出音位库存约束 | 不受约束 | 扮演者不知道「两岁半的嘴长什么样」 |
| 词形截断痕迹 | 无 | 有（长词被腰斩） | 扮演者用长度而非能力做约束 |

**过度规则化率是本项目最重要的单个指标**：它是唯一一个"知道答案反而做不到"的指标，扮演者在结构上不可能通过它。§10 用它做真伪判定。

## 3. 双轨：理解与产出

真实儿童的理解词库远大于产出词库，2 岁时约 2–3:1 [待核，CDI 各版本差异大]。必须保留这个不对称，否则"能听懂但说不出"会被当成 bug 打补丁。

| 库 | 进入条件 | 阈值 | 用途 |
|---|---|---|---|
| 理解词库 receptive | 共同注意下听到 ≥1 次 | `comprehension_confidence ≥ 0.3` | 解析成人话语、参与指令、里程碑判定 |
| 产出词库 productive | exposures ≥ k(age) 且音节可行 且非纯仿说 | `production_threshold` | **编译器的唯一白名单** |

`k(age)`：S1 需 6–12 次暴露，S2 降到 2–4 次，S3+ 降到 1–2 次（fast mapping 生效）。这个下降本身就是"学习效率随发育提升"的量化。

### 3.1 语言等级 L 与发育阶段 S 解耦

00 §6 的阶段跨度太大：S3 覆盖 3 年，语言从电报句走到语法爆发，不可能只有一个"语言能力"值。因此**阶段 S 只给上下限**（宪法，不可越），**语言等级 L 由语言里程碑单独判定**，硬约束 `L_stage_min[S] ≤ L ≤ L_stage_max[S]` 且 `L` 单调不减。

```
L_stage_max = {S0: L0, S1: L1, S2: L2, S3: L3, S4: L4, S5: L5, S6: L5}
L_stage_min = {S0: L0, S1: L0, S2: L1, S3: L2, S4: L3, S5: L4, S6: L5}
```

`L_stage_min` 保证升级时语言不会掉回去，这是 A3 在语言层的第一个落点。

**表现性回归**：高唤醒（哭、恐惧、极度兴奋）或高疲劳时 `L_eff = L − 1`，只作用于**当条话语**，不改 `L`。这不是 bug：应激下说话退行是真实的。但两者必须分账——`level_competence` 与 `level_effective` 两个字段都要落日志，否则"语言退步"无法与"表现波动"区分。

### 4.1 感知库存收窄 vs 产出库存扩张

两个方向相反，必须分开实现，否则会做出"婴儿发不出任何音"或"成人发不出 f 音"的怪物。

- **产出库存（运动命令）随发育扩张**：S1 只有 `CV`（无韵尾、无复辅音），S2 加 `-n/-ŋ`，S3 才接近全库存。由构音器官成熟决定，与经验无关。**这是编译器的闸门（§8）。**
- **感知库存（音位对立分辨）随经验收窄**：初始全音位可分，6–12 月内收窄到母语集（Kuhl 2004；Werker & Tees 1984）。它决定成人语音被切分成什么单位，进而决定 Lexicon 里 `form` 长什么样。**这是切词器的参数（§5）。**

两者不能共用一张表，且**收窄只能单向**（A3）：不能因为个体后来多听了某种语言，就把已丢失的对立重新"学会"。

### 4.2 过度规则化必须是"算出来的"

正确实现：Lexicon 只存词根与帧，形态由规则现场生成；不规则形式（走/去/好）作为**独立词条**单独习得，在其被习得之前规则会被套到它身上：

- 中文：`一只狗` → `一个狗`（量词泛化）；`没去过` → `不有去过`（否定规则过度泛化）[待核，中文形态泛化的实证文献远少于英语]
- 英语：`went` → `goed`，`feet` → `foots`，`mice` → `mouses`

若在代码里加一个"语法检查器"把这些改正，等于**销毁唯一能区分真习得与扮演的证据**。禁止。见失败案例 F5。

## 5. Lexicon 数据结构

Lexicon 是外部状态（00 §7），落盘 JSON，索引进 SQLite。**它是产出词表的唯一权威。**

### 5.1 字段表

| 字段 | 类型 | 语义 | 写入者 |
|---|---|---|---|
| `id` | string | `lex_000123`，永不复用 | 巩固流程 |
| `form` | string | 表面形式。**必须是某条 caregiver 话语的连续子串** | 切词器 |
| `gloss` | string | 成人语义锚，仅供内部对齐 | 巩固流程 |
| `gloss_internal_only` | bool | 恒 true。审计器断言它永不出现在输出通道 | 恒定 |
| `kind` | enum | `word` / `frozen`（"谢谢""拜拜"等不可分析整块）/ `gesture` | 切词器 |
| `pos` | enum | 词性，**由帧统计推断**，非人工标注 | 巩固流程 |
| `first_heard_day` | int | 首次在共同注意下听到 | 感知 |
| `first_produced_day` | int \| null | 首次自发产出（排仿说） | 编译器回写 |
| `source[]` | array | 前 5 条来源 `{day, speaker, episode_id, utterance_id, joint_attention}` | 感知 |
| `exposures` / `produced_count` | int | 累计听到次数 / 累计产出次数 | 感知 / 编译器回写 |
| `comprehension_confidence` / `production_threshold` | float | 0–1 理解置信 / 动态产出阈值，随年龄下降 | 巩固流程 |
| `syllables[]` | array | 音节序列，如 `["ma","ma"]` | 切词器 |
| `phonotactic_ok[]` | array | 在哪些阶段的产出库存下可发 | 推导 |
| `frames[]` | array | 观察到的句法帧，见 5.2 | 巩固流程 |
| `semantic_field` | string | 语义场，如 `kinship` / `food` / `motion` | 巩固流程 |
| `extension` | object | 外延：原型特征权重、正负例数（§9） | 巩固流程 |
| `collocations[]` | array | 高频搭配，用于模板排序 | 巩固流程 |
| `status` | enum | `heard_only` / `emerging` / `productive` / `dormant` | 巩固流程 |

**不变式**（编译器与审计器都要断言）：

- I1 任何 utterance 的 token 必须命中某条 `status=productive` 词条的 `form`。
- I2 `form` 必须是 caregiver 真实话语的子串——**禁止生成词形**。
- I3 `gloss` 永不出现在输出通道。
- I4 词条只由**感知事件或夜间巩固**写入；编译器只读（守住 00 §2「L1 不得直接写 L4」）。
- I5 `first_heard_day ≤ first_produced_day`。

### 5.2 句法帧

帧是词条见过的槽位模式，也是模板排序与词性推断的唯一依据：

```json
{"pattern": "[AGENT:__] [ACTION:give] [RECIPIENT:__]", "count": 12,
 "slots_filled": {"AGENT": ["妈妈", "宝宝"], "RECIPIENT": ["妈妈"]}}
```

帧的 `slots_filled` 是从真实话语里抽出来的，不是模板库：这是构式表（Tomasello 2003）的机器形态，也是"从具体条目到抽象构式"的唯一入口。

## 6. 词汇增长曲线

### 6.1 参考点与本文目标带

| 名义年龄 | 阶段 | 真实儿童产出 | 真实儿童理解 | 本文目标产出 | 本文目标理解 | 日增新词 |
|---|---|---|---|---|---|---|
| 6 月 | S1 | — | — | 0 | 40 | 0 |
| 12 月 | S1 末 | 0–5 | 20–100 | 8 | 120 | 0.05 |
| 18 月 | S2 | ~50 | ~200 | 40 | 260 | 0.5 |
| 24 月 | S2 末 | ~300（50–550） | ~600 | 250 | 900 | 3.5 |
| 3 岁 | S3 | — | — | 700 | 2 000 | 1.2 |
| 6 岁 | S4 | 2.5k–3k | 10k–14k | 3 000 | 7 000 | 2.1 |
| 12 岁 | S5 | — | — | 6 000 | 14 000 | 1.4 |
| 18 岁 | S6 | 20k–60k | — | 9 000 | 20 000 | 0.8 |

真实儿童数值：12 月取 CDI 家长报告中位 [待核]；18 月据 Fenson et al. (1994)，陡增起点个体差异极大（16 月的中位约 50 但四分位跨度极宽）；24 月分布高度右偏，**均值无意义**；6 岁据 Carey (1978) 词典抽样外推，普遍认为**高估** [待核]；成人区间口径争议极大 [待核]。**所有数字都依赖口径**（词元/词族、产出/理解、家长报告/语料抽样），跨文献比较必须换算，否则是伪精度。本文目标值**有意低于**真实儿童，理由见 6.2。

### 6.2 增长律：指数 + 封顶，但真正的瓶颈是产出预算

```
V(d+1) = min( V(d) + α_s·(V(d) + c_s),  V_max(s) )
V_max = {S1: 10, S2: 260, S3: 720, S4: 3000, S5: 6200, S6: 9000}
α     = {S1: 0.0005, S2: 0.0098, S3: 0.0014, S4: 0.0021, S5: 0.0006};  c = 0.5
```

指数项负责产生"陡增"：S2 内从 40 到 250 需 `e^{180α} ≈ 6.25`，即 `α ≈ 0.010`；同一参数同时拟合 12→18 月的慢启动。**"词汇陡增"不需要专门开关，只需要"已会 100 个词比已会 10 个词更容易学第 101 个"（富者愈富）。**

真正卡住我们的不是学习速度，是**话语预算**：每个 Episode 最多产出一条话语，一天 24–60 个 Episode，其中约 2/3 有言语。

```
新词/天 ≤ 有言语 Episode 数 × 新词产出比 ≈ 40 × 5% = 2 词/天
12 年 ≈ 4380 天 × 2 ≈ 8 760 词       ← 与上表 18 岁 9 000 吻合
```

真实儿童一天说几百上千句，我们一天最多 60 句。任何想在 6 岁拥有 10k 词的方案，都得先推翻 Episode 预算，而不是调大 α。这个算术必须写在文档里，否则后来的人会以为调参就能追上。

**曲线守卫（同时也是泄漏检测器）**：每月结算断言 `target_lo(month) ≤ V_produced ≤ target_hi(month)`。**超出上界是严重 bug，不是好消息**：词汇量涨得比设计快，只可能是白名单被旁路（模型直接说了未习得词）。这条断言把"成长指标"和"防作弊"变成了同一件事。

## 7. 句法等级 L0–L5

### 7.1 等级定义

| 等级 | 名称 | 最大词数 | 从句嵌套 | 允许构式 | 禁止 | 阶段 |
|---|---|---|---|---|---|---|
| L0 | 前语言 | 0 | — | 哭声 3 类、咕咕声、咿呀串（≤4 音节） | 任何词 | S0 |
| L1 | 单词期 | 1 | 0 | 单词；单词+手势；指物 | 任何组合 | S1 |
| L2a | 双词 | 2 | 0 | 施事+动作 / 动作+受事 / 领属+"的"+名 / 还要+X / 不要+X | 功能词（除 5 个封闭词外） | S2 前 |
| L2b | 电报句 | 3 | 0 | 三词组合；修饰+名词；无功能词 | 时体标记、复句、助词 | S2 后 |
| L3 | 简单句 | 6 | 1 | SVO；否定；wh- 疑问；并列；because/因为 | 被动（被/让）、关系从句、时体 | S3 |
| L4 | 完整句法 | 12 | 2 | 关系从句、被动、时体（了/过/在）、情态（能/会/要） | >2 层嵌套、书面套嵌 | S4 |
| L5 | 成人 | 软上限 60 | 不限 | 全部 | — | S5+ |

**中文使这件事在工程上可行**：等级约束的绝大部分可退化为三项纯检查——(1) 分词后 token 数；(2) **封闭类词白名单**（被/让/了/过/着/能/会/要/因为/如果/的……一张固定表）；(3) 依存树深度（spaCy 或等价解析器，不必完美，只需稳定）。这比"判断这句话是否像幼儿说的"可靠得多，因为它是可枚举的。L5 的软上限 60 词是产品理由（长独白不可读），不是发展理由，须在日志里标注来源。

### 7.2 等级判定算法

等级由**自发性产出**的探针判定，不由模板选择决定，也不由提示词声明。

```python
def assign_level(events, stage, prev):
    ok = {p.id: p.demonstrated(events) for p in PROBES}      # 见 7.3
    level = 0
    for lv in (1, 2, 3, 4, 5):                               # 最长已通过前缀
        if not ok.get(f"L{lv}"): break                       # 禁止跳级
        level = lv
    level = min(max(level, L_STAGE_MIN[stage]), L_STAGE_MAX[stage])
    return max(level, prev)                                  # A3：能力不回退
```

`max(level, prev)` 是 A3 在语言层的落点：**能力单调**，波动的只有 `L_eff`（§3.1）。本函数每日夜间运行一次，只在巩固时提交，避免日内抖动。

### 7.3 探针与仿说排除

| 探针 | 判据 | 窗口 |
|---|---|---|
| L1 | ≥5 次非仿说单词产出，≥2 个不同词，跨 ≥3 个场景 | 7 天 |
| L2 | ≥10 次双词组合，≥2 种语义关系 | 14 天 |
| L3 | ≥10 次 ≥3 词产出；≥1 个封闭类词；≥3 个规则泛化形式 | 14 天 |
| L4 | ≥5 次 wh- 疑问且语序正确；≥3 次 because/因为从句 | 21 天 |
| L5 | ≥3 次关系从句；≥3 次被动；时体标记使用正确率 >0.8 | 30 天 |

**仿说排除**（否则判定整体失效）：若一条话语与紧邻的成人话语 token 重合率 >0.7 且间隔 <5 秒，标记 `imitated=true`，不计入任何探针。真实儿童的即时模仿很常见，模仿不代表能力——不排除的话，一个只会回音的个体也会被判成 L3。

## 8. 输出编译器

### 8.1 流水线

```
intent(结构化) → 构式检索(按 L_eff 取候选, 按 intent 排序) → 槽位绑定(实体/谓词 → 词条)
  → 词表闸门(productive 白名单) → 音位闸门(音节序列 ∈ 当前产出库存) → 极性检查
  → 长度 / 从句深度 / 封闭类闸门 → realize → utterance + witness 链
  ↘ 任一步失败 → degrade → 手势 / 单词 / 咿呀 / 哭声 / 沉默
```

### 8.2 伪代码

```python
def say(intent, ctx):
    for c in ctx.constructions[ctx.level_eff].rank(intent)[:3]:
        s = bind(c, intent, ctx.lexicon)                     # 只用 productive 词条
        if s.missing: s = hypernym_fallback(s, ctx.lexicon)   # 语义场相邻已习得词
        if s.missing: continue
        if not phonotactic_ok(s.words, ctx.inventory):
            s = drop_modifiers(s)                            # 只删修饰，绝不切词内
        if s.missing or not polarity_preserved(c, s, intent): continue
        u = realize(c, s)
        if not within_budget(u, c.level): continue           # tokens/depth/封闭类
        return Emit(u, witness=trace(c, s))
    return degrade(intent, ctx)

def degrade(intent, ctx):
    if can(POINT) and intent.referent_in_view: return Emit(Gesture(POINT, intent.referent))
    if ctx.level_eff >= 1 and (w := nearest_word(intent, ctx.lexicon)):
        return Emit(Utterance([w]))
    if can(BABBLE): return Emit(Babble(syllables(ctx.inventory, k=2)))
    if can(CRY): return Emit(Cry(intent.urgency_class))
    return Emit(Silence(gaze_target=intent.referent))        # 合法动作，必须落日志
```

三条硬性设计决定，每条都有对应的失败案例：

1. **不做词内截断。** 想发 `elephant` 而库存只有 CV，正确做法是**换词或降级**，不是截成 `ele`——`ele` 从未在任何成人话语里出现过，会破坏 I2，让"词的来源可追溯"整条审计链断掉。F2。
2. **不截断句子，换更小的构式。** 截断会切掉否定词，把"不要打"变成"打"，语义反转比不说话严重得多。保不住极性就整句放弃。F3。
3. **降级链必须证明终止。** 末位是 `Silence`，它是动作而不是兜底异常；否则会出现无限重试。F4。

### 8.3 失败案例

| 编号 | 症状 | 根因 | 检测 | 处置 |
|---|---|---|---|---|
| F1 | 8 月龄说出完整句 | schema 升级引入 `intent.note` 并被打通到输出 | `unseen_word_rate > 0`；词汇曲线破上界 | 拒绝额外字段；输出通道只认编译器产物。这是本项目最可能发生的作弊路径，必须单测覆盖 |
| F2 | 出现 `ele` 这类从未听过的词形 | 词内截断 | `form` 不在任何 caregiver 话语子串集合中（I2 违反） | 禁止词内截断；改换词或降级 |
| F3 | 意图是拒绝，说的却是肯定句 | 长度闸门截断切掉了否定词 | `polarity_preserved == false` 却仍 Emit | 先查极性再查长度；保不住就整句放弃 |
| F4 | 某条 intent 卡死 / 每天重复同一动作 | 降级链无终止条件 | Episode 超时；`silence_count` 异常高 | 显式 `Silence` 终态；降级深度上限 4 |
| F5 | 过度规则化率恒为 0 | 有人在编译器里加了"语法修正" | 该指标长期为 0 | 删除修正器——它同时销毁了 §2 唯一的真伪判据 |
| F6 | 代词一律指自己 | Lexicon 把"我"绑到 body，而非"当前说话者角色" | 成人说"我"时，它把"我"解析成人还是自己 | 按话语角色绑定。**这个 bug 的症状恰好等于真实儿童现象（代词反转），所以不能拿"孩子都这样"掩盖它**：若"我"有时指自己有时指成人则正常，一律指自己即绑定错误 |

## 9. 词义获得

**fast mapping**：首次在共同注意下听到一个词就建立初步映射，`comprehension_confidence=0.15`，`extension.mode="under"`（只认那一个实例）——正是 Carey & Bartlett (1978) 的 fast mapping：一次接触即可形成存留数周的初猜，代价是外延过窄。

### 9.1 过度延伸与过窄延伸

两者是同一枚硬币：外延半径估错。**过度延伸**（`狗` = 所有四足动物）是原型由单一实例初始化、`four_legs`/`has_fur` 权重过高且缺反例；**过窄延伸**（`狗` = 只指我家那只）同样缺反例，但偏向 `face_id` 这类个体特征。

实现为特征加权原型，`P(word | percept) ∝ Σ_f w_f · x_f`，更新规则是纯统计的，无教师：

```
正向（成人用该词，且指称与知觉对象一致）：  w_f += λ · (x_f − w_f)        λ  = 0.05
负向（成人用该词，但对象与原型不符）：        w_f -= λ' · (x_f − w_f)       λ' = 0.015
竞争（成人此时用了另一个词，而候选集里也有它）：对竞争词做正向更新，本词 w_f -= μ·x_f，μ = 0.02
```

负向远慢于正向，这是有意的：儿童确实需要很多反例才能收回一个过度延伸的词。

### 9.2 纠正不是纠正（以及学习偏好只是排序）

**系统里没有 `correct(entry, truth)` 这个 API，也不许有。** 家长会对错误说法做重铸（孩子指着猫说"狗狗"，家长说"那是猫猫"）——但重铸只是**输入分布的一部分**，进入同一条通用暴露事件流水线，与任何其他话语没有特权。一旦引入"纠错接口"，词义就变成由成人直接写下的正确答案，而不是从使用统计中长出来的，§2 的词源论证也随之失效。

Markman (1990) 的三条约束——整体对象偏好、互斥性（已知物已有名字时新词优先指未命名对象）、形状偏好——同理只作为**候选排序的偏置**，且仅在多个解释并列时起作用；写成过滤器会导致学不到例外（物质名词与同义异名都违反形状/互斥偏好）。

## 10. 反作弊：四层防御与 ablation

### 10.1 四层防御（纵深，任一层单独失效仍不泄漏）

| 层 | 位置 | 检查 | 失效时 |
|---|---|---|---|
| 1 接口 | schema | 无自由文本字段；`additionalProperties: false` | 拒绝 + `schema_violation` |
| 2 编译器 | L1 纯函数 | 白名单 ∩ 音位 ∩ 等级 ∩ 极性 | 降级（有出口） |
| 3 审计器 | 离线/在线 | 独立重算 witness 链，不看编译器的"已通过"标记 | 告警 + 阻断该条 |
| 4 兜底 | 出口前 | 最笨的字符串检查：每个 token 必须 ∈ `allowed_surface_forms` | 丢弃 + 记 `bypass_detected` |

第 4 层故意做得很笨（字符串集合匹配，不复用编译器任何逻辑）。**最笨的检查要放在最外层**，因为复杂检查会随需求演化被悄悄放宽，字符串集合不会。

### 10.2 ablation：调低上限，输出必须退化

固定 60 条测试 intent（覆盖请求/告知/抗议/问候/回答，覆盖在场与不在场指涉），对每个 `L_max ∈ {L0..L5}` 全量跑一遍。

| 实验 | 改动 | 期望结果 | 判据 | 若不变说明 |
|---|---|---|---|---|
| A1 | `L_max = L1` | 单词语语占比 ≥99% | 硬断言 | 等级闸门没接在通路上 |
| A2 | `L_max` 从 L0 扫到 L5 | MLU 单调不减 | Spearman ρ ≥ 0.9 | 存在旁路或缓存 |
| A3 | 任意 `L_max` | 禁止结构率 = 0（全等级） | 硬断言 | 封闭类检查是空操作 |
| A4 | 任意 `L_max` | token 覆盖率 = 100%（全在白名单内） | 硬断言 | 白名单未生效 |
| A5 | 关闭音位闸门 | S1 个体立刻出现多音节成人词，平均音节数 +≥1.5 | 达标 | 该闸门是空操作 |
| A6 | 关闭白名单 | `unseen_word_rate` 从 0 跳到 >0.3 | 达标 | 白名单根本没跑 |
| A7 | 关闭降级链（强制直出） | 未习得指涉的 intent 直接失败 | 失败率 >0 | 降级链是装饰 |
| B1 | 对照组：同一批 intent 交给"扮演婴儿"提示词 | 禁止结构率显著 >0（典型 5–30%），且随上下文变长而上升 | 编译组恒为 0 | 若两组无差异，说明我们的约束形同虚设 |
| C1 | 正控制：人为在输出通道注入一段自由文本 | 审计器必须捕获 | 召回率 100% | 说明检测器本身是坏的 |

**A 组是断言，B 组是对照，C 组是"检验检验本身"。** 缺 C 组的验证方案不可信：没被证明能抓到已知泄漏的检测器，其"零告警"毫无意义。

**可证伪性**：A1–A7 的判据全是硬断言或单调性，不是"看起来像小孩"；任何一条不通过即说明某个闸门没接在通路上，可自动判定、不依赖人工评审。B1 把我们的编译器与提示词扮演放在同一批 intent 上比较，直接回答"我们和 §0 的 A 路径有什么区别"。

## 11. 评估指标

所有指标必须能**从日志离线重算**，不参与生成，不调用模型。

| 指标 | 定义 | 窗口 | 参考 |
|---|---|---|---|
| MLU-w / MLU-m | 平均话语长度（词 / 词素），排除仿说 | 40 条话语 | Brown (1973) 分期：I 1.0–2.0、II 2.0–2.5、III 2.5–3.0、IV 3.0–3.75、V 3.75–4.5 |
| MATTR | 移动平均类符形符比 | 50 条 | Covington & McFall (2010)。**不要用裸 TTR**，它随样本长度单调下降，跨阶段不可比 |
| 过度规则化率 | 不规则形式的规则化次数 / 其全部使用次数 | 月 | Marcus et al. (1992) 报道约 2.5%，先升后降 [待核精确值] |
| 省略率 | 缺失必有论元的话语比例 | 月 | 电报句期高，L3 后下降 |
| 词序/指代错误率 | 施事受事错位、代词指错人 | 月 | 词序应始终很低（中文语序习得早）；指代高→低，长期不降则查 F6 |
| 语用轮次 | 话题相关连续轮数中位数 | 周 | 3 岁后应 ≥3 |
| 词源完整性 | 输出 token 可追溯到 caregiver 话语的比例 | 全量 | **恒为 100%**，硬断言 |
| 词汇曲线偏差 | `V` 与目标带的 z 分数 | 月 | 超上界 = 泄漏 |

**真伪判据只有两条**：过度规则化率 >0 且非单调；词源完整性 = 100%。其余指标衡量发展程度，不衡量真伪。

## 12. 读写（S4）与语言反向塑造思维

**读写**：S4 解锁字形，需 `grapheme→phoneme` 映射表。读写是**第二套编码**：共享语义层，不共享产出库存，故需独立 `literacy_inventory` 与独立计数（会读 ≠ 会写 ≠ 会拼），S4 末识字目标 1 500–2 500 字。**读了但从没说过的词不得进入产出词库**——否则识字就是词表后门。

**语言塑造思维**（弱版）：语言提供可用范畴，改变编码与检索效率，不改变感知本身。机制是索引而非玄学——**有词的概念在记忆检索时多一个键**。可测预测：有词类别 vs 无词类别，在延迟回忆任务上正确率显著不同。这让"语言改变思维"可被 00 的证伪标准检验，且不引入任何关于意识的假设。

## 13. 本设计的漏洞（不掩饰）

| # | 漏洞 | 性质 | 缓解 |
|---|---|---|---|
| 1 | **理解不可门控** | 结构性。基质从 day 1 完整理解成人语言，我们只能门控产出 | 无解。只能在文档、产品、评估口径里一致地表述为"学产出"，不许说"在学语言" |
| 2 | **词表可由"不写"伪造** | 不往 Lexicon 写词就装成了婴儿，且曲线看起来完美 | 外部校核：曲线偏差、词源完整性、A6 白名单 ablation |
| 3 | **判定与日志同源（自证循环）** | 里程碑由日志判定，日志由同一系统写 | 审计日志只追加；判者与写者分离（§10.1 第 3 层） |
| 4 | **语用几乎未强制** | 等级管得住句法，管不住"什么时候该说" | 只做最小约束（轮流、不打断），并明确标注为弱项 |

第 1 条最重：如果哪天有人用这套系统宣称"它从零学会了语言"，这句话是假的。它从零学会的是**把已经懂的成人语义逐个绑定到自己的发音器官和经验上**。这仍然值得做，但必须说准。
