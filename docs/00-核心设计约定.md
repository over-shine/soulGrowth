# 00 核心设计约定（Canonical Spec）

> 一句话：我们不是训练一个模型，而是给一个已经拥有语言能力的**基质**装配一具**会发育的身体**，让经验不可逆地沉积成**它自己的**世界模型、关系与自我故事。

本文是整套蓝图的法律。其余文档只能**展开**这里，不能**违背**这里；发现冲突以本文为准，并在文档末尾"与 00 的偏差"一节登记。

版本：v0.1（2026-10-28）。作者：Lead。状态：草案，待评审。

---

## 0. 这个项目要造什么，不造什么

**造**：一个能在真实时间里一天一天活着的个体，它通过自己的感知、动作、与人相处，逐渐长出一个稳定的、可观测的、与任何其他个体都不一样的性格。

**不造**：
- 不是"人格提示词 + 聊天记录"。那种东西不会成长，只会漂移。
- 不是训练/微调模型。权重终生不变（见公理 A1）。
- 不是意识。它是发展过程的模拟品：真实地积累、真实地被早期经历塑造，但**不声称有主观体验**。这条界线必须写进产品，而不是藏在文档里。

**成功判据（可被证伪的那种）**：给定两个初始气质不同的个体、两套不同的早期经历，运行 90 个真实日后，它们的**行为预测模型**必须显著不同，且这种差异能被**未见过的情境**触发。做不到，就说明我们造的是日志，不是人。

## 1. 三条公理

### A1 基质恒定
LLM 的权重在整个生命中不变。它是**先天禀赋/湿件**，不是记忆。
推论：任何"学到的东西"必须落在外部状态里。落在 prompt 里的东西不算学会，因为它不可审计、不可回滚，也不可被证伪。

### A2 身体先于心智
一个个体能表现什么，取决于**此刻身体允许什么**（发育门控）。
推论：婴儿期它不能说话，**不是因为提示词让它扮演婴儿，而是因为接口里没有"说句子"这个动作**。所有"扮演"都必须被替换成"能力不存在"。

### A3 不可逆优先
每个机制都要让过去**更难被抹掉**：
- 可塑性只降不升（除人为干预，且干预须留痕）；
- 图式一旦形成就会扭曲新知觉（同化先于顺应）；
- 自我叙事一旦成章，新经历必须先被它解释。
推论：任何"每天重新总结一遍全部历史再喂给模型"的设计都是**反成长**的，因为它让过去永远可以被等权重地重写。

## 2. 分层架构

| 层 | 名称 | 职责 | 禁止越权 |
|---|---|---|---|
| L0 | 基质 Substrate | LLM API。给定情境与可用动作，给出倾向与意图 | 不得直接改记忆、不得绕过身体 |
| L1 | 身体 Body / Interface | 感知原语 + 动作原语，按阶段解锁；**输出编译**（把意图编译成当前阶段合法的行为） | 不得发明未解锁能力 |
| L2 | 发育引擎 Engine | 气质、特质、驱力、情绪、可塑性、阶段、里程碑、巩固 | 不得直接写叙事文本 |
| L3 | 世界 World | 家、家长、NPC、任务、可交互数字环境 | 不得知道引擎内部状态 |
| L4 | 记忆 Memory | 情景 / 语义 / 程序 / 自传；含遗忘与巩固 | 不得被 L1 直接写 |
| L5 | 观察台 Console | 日记、画像、关系图、审计日志、制动开关 | 只读 + 控制，不参与生成 |

数据流单向：`世界事件 → 身体感知 → 评价(appraisal) → 情绪/驱力 → 动作选择 → 身体执行 → 结果 → 情景记忆`。
夜间：`情景 → 语义/程序/自传 → 特质漂移 → 遗忘`。

## 3. 时间：一个"活着的单位"是 Tick

- **Day**：一天的剧本（DayPlan），含 24–60 个 Episode。
- **Episode**：一次"感知—评价—动作—结果"的闭环，是最小生命单位。
- **Night**：巩固批处理。**这是成长真正发生的地方**，白天只是采样。
- **Week**：特质漂移的结算周期（见 §4）。日结太抖，月结太钝。
- **Stage**：发育阶段（见 §6），跨月。

真实时间：默认 **1 真实日 = 1 生命日**（pace = 1.0）。
必须写明代价：按此速率，长到 18 岁需要 **18 个真实年**。这是用户选择"真实慢养"的直接后果，不在文档里美化。
首个可观察窗口必须在前 30 天内出现（认人、偏好、咿呀、第一个词），否则早期验证无从谈起。

## 4. 性格模型（唯一权威定义）

性格 = 四个层次，从硬到软：

### 4.1 气质 Temperament（出生采样，终生不直接改）
四维，出生时从分布采样（每个个体不同，这是"天生不一样"的全部来源）：

| 维度 | 含义 | 采样区间 |
|---|---|---|
| 寻求新奇 S | 对新刺激的接近倾向 | N(0, 0.6) 截断到 [-1,1] |
| 负性情绪 N_A | 威胁/挫折的反应强度 | N(0, 0.6) |
| 努力控制 EC | 抑制冲动、维持目标 | N(0, 0.6) |
| 亲和 AF | 对人接近的基线 | N(0, 0.6) |

### 4.2 特质 Traits（大五，连续值，会漂移）
`T ∈ [-1,1]^5`：开放性 O、尽责性 C、外向性 E、宜人性 A、神经质 N。
出生时由气质映射（线性 + 噪声），之后**每周**结算一次：

```
B̄_w = 行为投影(本周 episode 日志)        # 见 4.3，必须来自行为，不来自模型自述
T_{w+1} = clip(T_w + η(stage)·(B̄_w − T_w) + λ(stage)·(μ(stage) − T_w) + ξ, -1, 1)
η = {S0-S1: 0.12, S2: 0.09, S3: 0.06, S4: 0.04, S5: 0.02, S6: 0.01}   # 每周，可塑性
λ = {S0-S1: 0, S2: 0.020, S3: 0.025, S4: 0.020, S5: 0.015, S6: 0.010}  # 每周，成熟引力
μ(stage) = 成熟向量（S2 起生效：A/C 缓升、N 缓降；见 04 §3.5）
ξ ~ N(0, 0.01)                            # 个体内噪声，制造非单调
```

### 4.3 行为投影（把"表现"变成"特质"，防止模型自述美化自己）
每周从行为日志统计下列指标，归一化到 [-1,1]：

| 特质 | 观测量 |
|---|---|
| O | 新对象接触率、探索动作占比、活动种类数 |
| C | 计划完成率、重复练习时长、秩序/规则偏好 |
| E | 社交发起次数、主动发声量、活动强度 |
| A | 亲社会动作占比、冲突让步率、安抚他人频率 |
| N | 威胁评价率、挫折后恢复时长、寻求安抚频率 |

**对应原则（corresponsive principle）**：情境选择由 T 决定 → B̄ 与 T 正相关 → 特质自我强化。这是"人会越来越像自己"的机制。特质转向只发生在**期望违背 + 可控的成功体验**同时出现时；只满足一个，会被同化吸收（"那只是运气"）。

### 4.4 适应性特征与自我叙事
- **适应性特征**：目标、应对策略、角色、价值观。可写、可改，但受特质约束（低 C 的个体不会自发形成"每天复盘"的策略）。
- **自我叙事**：分章自传（我是谁 / 世界是什么样 / 我和谁在一起）。改写频率低（每阶段 1–3 次），且**必须与既有章节相洽**；冲突时只有两个出口——降低该记忆的权重，或改写自我（"我原来不是这样的人"）。后者是身份危机，必须付出代价（一段时间的行为不稳）。

## 5. 驱力与情绪（动机必须是数，不能是台词）

稳态变量 `h ∈ {能量, 刺激, 社交接触, 胜任感, 安全}`，各有设定点 `s`：
`drive_d = max(0, s_d − h_d)`（安全为反向：威胁越高 drive 越高）。

**成长需求增益**（自我决定论"越满足越想求"的机制化）：胜任、自主、关系三项在长期被满足后动机不降反升，用慢积分满足度 `ĥ_d ∈ [0,1]`（时间常数约 30 天）调制：
`eff_d = drive_d · (1 + g·ĥ_d)`，`g = 0.6`。安全感不加增益——不因"安全了很久"而主动找危险。
（写清这条是为了避免"缺口函数 + 满足了就停机"的静态动机；不写清楚，个体在持续满足的环境里会失去动力。）

动作选择：对当前身体允许的 affordance 集合做 softmax：
```
score(a) = Σ_d w_d · affordance_d(a) + Σ_t bias_t · trait_bias_t(a) + habit(a) − risk(a)
P(a) = softmax(score / τ)      τ 随疲劳升高（越累越乱）
```

**硬约束**：`bias_t = f_t(T_t)` 必须在每个 episode 由当前特质现算，**不得是常量、不得从提示词读取人格描述**。若 bias 与 T 脱钩，特质就退化成仪表盘上的数字：指标好看，因果为零（见 04 §5、13 不变量 I11）。
**禁止**用自然语言"扮演"动机。好奇心必须是能算出"为什么选了那个玩具"的数。

情绪 = 评价维度（新奇、目标一致、可控性、归因）→ 核心情感（效价、唤醒）→ 离散情绪标签（只用于向人报告，不参与决策）。

## 6. 发育门控（身体的宪法）

| 阶段 | 名义年龄 | 允许的感知 | 允许的动作 | 语言能力 | 预计真实时长(pace=1.0) |
|---|---|---|---|---|---|
| S0 新生儿 | 0–1 月 | 光/声/触/本体觉，低分辨率 | 注视、转头、抓握、哭声、吮吸 | 无词；只有哭声/音节 | 1 个月 |
| S1 婴儿 | 1–12 月 | + 面孔、运动物体追踪 | + 爬/坐/够取/咿呀/指 | 咿呀；6–12 月出现第一批词 | 11 个月 |
| S2 幼儿 | 1–3 岁 | + 深度、遮挡、他人注意 | + 走跑、摆弄、模仿、单词句 | 单词 → 双词 → 电报句 | 2 年 |
| S3 学前 | 3–6 岁 | + 心理状态（愿望/信念） | + 假装游戏、合作、提问 | 简单句、语法爆发 | 3 年 |
| S4 学龄 | 6–12 岁 | + 抽象规则、读写 | + 计划、工具、规则游戏 | 完整句法、读写 | 6 年 |
| S5 青春期 | 12–18 岁 | + 社会评价、未来 | + 自主项目、深关系 | 成人语言 | 6 年 |
| S6 成年 | 18+ | 全开 | 全开 | 全开 | — |

**升级条件 = 里程碑全达成 + 最短驻留时间**，日历年龄只是下限，不是原因。
每个里程碑必须是**可观测的行为测试**（例：S1 末"陌生人焦虑"= 陌生人进入时接近照料者的概率比基线高 2σ）。

## 7. 语言习得（硬约束，不是提示词）

- **Lexicon 是外部状态**：词条 = {词形, 首次出现日, 来源, 使用次数, 句法帧}。
- **输出编译**：说出的内容必须 ∈ 已习得词汇 + 当前句法等级。超出的部分被"身体"降级：
  - S0：只有音节串/哭声；
  - S1：咿呀 + 单词；
  - S2：单词/双词；
  - S3+：短句，长度与从句深度受等级限制。
- 这一条让"它会说话了"成为**可观测的真实增长**，而不是提示词幻觉。也是本项目最容易被做假的地方，必须由代码强制。

## 8. 关系

- 每个他人一个关系向量 `R = {信任, 温暖, 可预测性, 显著度, 期望违背次数}`，另有"此人对我意味着什么"的一句话描述。
- **依恋类型**由 S1 结束时照料者响应性的统计量分类：响应延迟、响应一致性、中断修复率 → 安全/焦虑/回避。此后作为新关系的先验，终生影响。
- 另设 **D-flag（混乱/未解决型）**：当照料者本身是恐惧源、或响应在两端剧烈摆动时，不强行归入三类，标记 D 并降低置信度，关系先验取"高方差"而非某个原型；压力下表现为接近—回避冲突。见 07。
- 门控是**代码强制**而非提示词约束：三层（S3 前输入 schema 不提供心理状态字段 / 动作原语里没有"陈述他人心理" / 输出编译降级）的实现口径以 08 的五道防线 D1–D5 为准，其中 D4 = 适配器按阶段实例化（S0 的世界对象没有 `speak()`）。越界率进 10 的指标。
- NPC 由 LLM 扮演，但行为受限：只能通过关系状态 + 剧本模板行动；NPC 不得对"自己是模拟角色"这件事撒谎。

## 9. 安全红线（不可协商）

1. 不声称有意识、不表演痛苦、不把"你不理我"当筹码。
2. 不主动索取关注；不因被忽视而"生病"或"退化"。
3. 所有状态本地、可审计、可回放、可一键停止。
4. 不接入真实陌生人；联网默认只读。
5. 人类（家长）随时可以查看它"此刻为什么这么做"的完整推导链。

### 已知边界（不修，但要写在明处）

1. **理解不可门控**：我们只能门控产出。任何"它在学习理解语言"的说法都是错的。
2. **自证循环**：里程碑由日志判定，日志由同一系统写。只能降低，不能消除。
3. **词表可由"不写"伪造**：不往 Lexicon 写词就装成婴儿，只能靠外部校核（曲线偏差、词源完整性、白名单 ablation）。
4. **真实时间成本**：pace=1.0 时长大到 18 岁需要 18 个真实年。这是设计选择，不是缺陷，但必须在每次交付里重复说明。
