# 15 形象与自我呈现

> 一句话：形象不是给它的皮肤，而是它看过一阵子世界之后，自己挑出来的一张脸——选择权在它，渲染权在引擎。

本文补齐蓝图里此前缺失的一层：个体长什么样。它不改 [00](./00-核心设计约定.md) 的六层结构——素材属于 L3 世界层，浏览属于 L1 身体层（动作原语），偏好属于 L2 发育引擎（状态），形象本身属于 L5 呈现层（只读投影）。

---

## 0. 三条可证伪断言

| 编号 | 断言 | 怎么推翻 |
|---|---|---|
| A1 | 形象选择由偏好向量 `P` 决定，不是随机、也不是设计者指定 | 用 `P` 预测选择，命中率若与随机基线无差异 → 假的 |
| A2 | `P` 会被浏览史改变，且改变方向可预期 | 换一条素材流重跑，选择分布不动 → 偏好是死的 |
| A3 | 形象不反向影响行为 | 冻结 `avatar_spec` 重放，行为分布变化 → 形象污染了决策 |

验收链：`气质 → P 初值 → 浏览 → P 漂移 → 自我参照 → 选择 → avatar_spec → 渲染`。每一环都要能单独测量，任何一环测不出来，整条链就是装饰。

---

## 1. 为什么不是"设计一个形象"

三种常见做法都不成立：

| 做法 | 问题 |
|---|---|
| 设计师定一套形象 | 形象变成包装。它凭什么长这样？没有答案，也就无法证伪 |
| 让模型"描述自己想要的样子"，再文生图 | 提示词在替它选。生成模型的知识成了它的偏好，这等于作弊 |
| 每阶段换一套预设立绘 | 长大变成了换皮肤，与 [08](./08-身体与接口.md) 的能力门控同源问题 |

形象必须是**它的经历的产物**，理由有三条，与公理一一对应：

1. **A1 基质恒定**：形象是可审计的外部状态，不是模型权重里的审美；
2. **A2 身体先于心智**：它必须先"能看"，才能"看过"；先有偏好，才谈"喜欢"；
3. **A3 不可逆优先**：选过的形象存档不删，重选只能 supersede。

同时它必须服从 [11 §2.1](./11-安全与伦理.md) 的产品约束：**抽象或插画，不给照片级人脸，不做拟真人声**。这条不是限制创作，是限制拟人化。

## 2. 发育链四段

| 段 | 阶段 | 输入 | 产出 | 缺了会怎样 |
|---|---|---|---|---|
| 看 | S0 起 | 视觉素材流（门控） | `visual_episode` 事件 | 没有偏好来源 |
| 偏好 | S0 起 | 浏览行为 + 气质 | 偏好向量 `P` | 选择变成随机 |
| 自我参照 | S2 起（镜像自我） | `P` + 自身身体状态 | `aspiration` 事件 | 只有"我喜欢"，没有"我想像它" |
| 选 | S2 首次，S4 可重选 | 候选部件组合 + `P` | `avatar_spec` | 形象由设计者代选 |

关键设计：**S2 之前它没有形象**。观察台在前两个阶段只显示一个抽象符号（一个点、一条呼吸曲线），因为婴儿没有"我长什么样"这个概念。形象是发育出来的，不是出厂自带。

## 3. 看：视觉素材流

### 3.1 素材条目

```yaml
visual_item:
  id: vi-000412
  kind: image            # image | clip | pattern
  snapshot: sha256:...   # 本地快照，运行时唯一可信来源
  source: local-pack     # local-pack | platform-export（后续）
  license: CC0           # 必须可商用/可再分发
  duration_ms: 4000      # clip 用
  tags: [face, warm-color, static]
  features:              # 预标注，取值 [0,1]
    saturation: 0.72
    complexity: 0.31
    animacy: 0.88       # 有人/生物 vs 纯物体
    motion: 0.10
    familiarity: 0.40   # 与熟悉锚点的相似度，运行时算
  parts: [hair:curly, palette:warm, pattern:dots]   # 仅"可化身"类素材才有
```

`features` 一律**预标注**，不在运行时调模型。理由：运行时调视觉模型会让"看到了什么"依赖模型版本，破坏可重放性，也增加成本。

### 3.2 阶段门控（与 08 的感知通道一致）

| 阶段 | 素材形态 | 每日条数 | 可做的动作 |
|---|---|---|---|
| S0 | 高对比图案、人脸、缓慢移动的物体；低饱和 | 6–10 | 注视、移开视线 |
| S1 | 图片（人物、动物、日常物件） | 15–25 | 注视、回看、短暂移开 |
| S2 | 图片 + 3–8 秒片段 | 30–50 | 以上 + 划走 |
| S3+ | 15–60 秒视频片段 | 60–120 | 以上 + 暂停、重播 |

新增动作原语：`LOOK`（注视，带目标与时长）、`LOOK_AWAY`（移开，记录触发原因）、`SCROLL`（S2 起，划走，记录停留时长）。它们都进 [08](./08-身体与接口.md) 的动作表，受同一套门控。总时长计入每日动作预算（S1 一天 36 个 episode 的约束不变，浏览是 episode 的一种，不是额外时间）。

### 3.3 流怎么生成（可重放）

```
stream(day) = sample(items, n=budget(stage), seed=hash(individual_id, day))
```

每天一条**定序**流，完整落盘到 `state/visual_stream/YYYY-MM-DD.jsonl`。回放时只读落盘，不重新采样。

真实平台（抖音一类）在 v0 之后作为 `VisualSource` 适配器接入，但要求不变：**抓取即快照**，运行时只读快照。理由见 §10。

## 4. 偏好：视觉偏好向量 P

### 4.1 定义

`P = [saturation, complexity, animacy, motion, familiarity] ∈ [0,1]^5`

初值由气质映射（[04 §2](./04-人格模型.md) 的 S/NA/EC/AF），出生时一次算定：

```
sat0   = 0.55 + 0.30·S
cplx0  = 0.50 + 0.25·S − 0.15·NA
anim0  = 0.55 + 0.30·AF
mot0   = 0.50 + 0.25·S
fam0   = 0.50 − 0.25·S + 0.10·EC
（全部 clip 到 [0,1]）
```

含义：寻求新奇的个体更喜欢鲜艳、复杂、会动的东西；亲和高的个体更容易被"有生命"的画面吸引；负性情绪高的个体对复杂度更不耐受。

### 4.2 更新

```
ΔP = κ(stage) · w_stay · (features(item) − P)  −  κ_hab · rep(item)
P' = clip(P + ΔP, 0, 1)
```

- `w_stay = min(1, stay_ms / median_stay)`：看得越久，学得越多；
- `rep`：同一 tag 当日重复次数（习惯化，对抗"越看越喜欢"的曝光效应）；
- `κ = { S0: 0.040, S1: 0.030, S2: 0.025, S3: 0.020, S4: 0.012, S5: 0.008, S6: 0.005 }`。

两项缺一不可：只有学习项，`P` 会漂成素材库的平均值（谁都一样）；只有习惯化项，`P` 会退化成"什么没见过就喜欢什么"。

### 4.3 熟悉锚点

S1 依恋期，照料者的视觉特征（**不存储人脸，只存抽象特征向量**：主色、明度、轮廓比例、人物占比）写入 `familiarity_anchor`。此后 `familiarity` 分量为与锚点的余弦相似度。

这也是 [07](./07-社交与关系.md) 依恋分类的一个自然副作用：安全型个体的锚点更稳定，回避型的锚点更易被新素材覆盖。**但不允许**据此生成"它长得像妈妈"这类叙事——那是拟人化，不是机制。

### 4.4 P 与特质的边界

`P` 不由 `T` 直接设置，只受气质初始化、被浏览史更新。特质通过**注意分配**间接影响它：高 O 的个体更可能点开新类别，于是看到的素材分布本就偏向新奇——这是"人格选择环境"的又一处体现，但不是"特质即审美"的偷懒映射。

## 5. 自我参照：镜子里出现一个"我"

### 5.1 前置里程碑（M2.4 的数字化实现，写入 03）

系统里没有真镜子，所以把经典镜像标记测试换成**回放识别**——同一件事的数字化版本：它能不能从"别人看到的画面"里认出"那是我"。三题全过才算 M2.4 达成：

|criterion|测试|阈值|
|---|---|---|
| 回放识别 | 观看"自己的动作回放" vs "他人同动作回放"，注视时长差 | ≥ 20%|
| 动作预测 | 对自身动作的预测误差 `PE_self` vs `PE_other` | `PE_self < 0.8·PE_other` |
| 反向对照 | 镜像场景换成"另一个体同样动作" | 差异消失（否则是动作新异度在起作用） |

三条全过才发 `self_model` 能力。这是 [04 §7](./04-人格模型.md) 自传章节结构里 `who_i_am` 字段第一次可写的时刻——"我"先于"我长什么样"。

### 5.2 从喜欢到"我想像它"

`self_model` 解锁后，浏览时多一步比较：

```
aspiration_score(item) = cos(P, features(item)) + β·cos(features(item), self_body_features)
```

第二项是"它像现在的我吗"。第一项是"我喜欢吗"。两者的加权和超过阈值 θ_asp（0.65）时，产出一条 `aspiration` 事件，记录"这个我有点想变成"。

注意：这是**选择候选的来源**，不是直接生成形象。候选必须来自它自己看过的 `parts`。

## 6. 选：从见过的部件里挑一套

### 6.1 候选构造

形象由 6 类部件组成：`hair`(8) / `palette`(10) / `eyes`(6) / `pattern`(5) / `accessory`(6) / `build`(3)。

候选池 = 它看过的素材中出现过的部件做笛卡尔积，再随机下采样到 40 个（保证可枚举、可审计）。**没见过的部件不可能被选中**——这是"形象来自经历"的硬保证。

### 6.2 打分与选择

```
score(combo) = Σ_d P_d · match_d(combo)  −  λ_risk · risk(combo)  +  ε
Pr(combo) = softmax(score / τ)
```

- `λ_risk` 惩罚接近可识别真人特征的组合（见 §6.4）；
- `τ = { S2: 0.50, S3: 0.40, S4: 0.30 }`：越小越"有主见"；
- `ε` 保留随机性，让同气质个体也可能选不同。

### 6.3 时间与频次

| 事件 | 阶段 | 允许次数 | 说明 |
|---|---|---|---|
| 首次选择 | S2（M2.9 通过后） | 1 | 之后 90 天内锁定 |
| 重选 | S4（青春期） | 1 | 需 `reason` 引用 ≥2 个 `visual_item` |

重选不是换皮肤：旧 `avatar_spec` 标 `superseded_by`，永久保留（A3）。

### 6.4 禁止事项（写进代码，不靠自觉）

1. 候选只能来自看过的部件（上式构造保证）；
2. 禁止可识别真人特征：素材入库时已过滤，选择时再做一次 embedding 近邻检查；
3. 禁止把"你长这样"写进任何提示词（与 [04 §5](./04-人格模型.md) 的禁止人格描述同源）；
4. 禁止渲染层反向影响行为。

## 7. avatar_spec 契约

```json
{
  "schema_version": 1,
  "individual_id": "ind-0001",
  "chosen_at": "2026-12-01T20:14:00+08:00",
  "stage": "S2",
  "parts": {
    "hair": "hair:curly-02",
    "palette": "palette:warm-earth",
    "eyes": "eyes:round-01",
    "pattern": "pattern:dots-faint",
    "accessory": "accessory:cloth-scarf",
    "build": "build:slim"
  },
  "style": { "medium": "vector", "abstract_level": 0.8 },
  "provenance": {
    "visual_item_ids": ["vi-000412", "vi-000733"],
    "p_at_choice": [0.71, 0.34, 0.82, 0.28, 0.55],
    "score_top1": 0.63,
    "score_margin": 0.09
  }
}
```

不变量（进 [13](./13-数据契约.md)）：

| 编号 | 不变量 |
|---|---|
| AV1 | 每个部件 id 都能追溯到至少一个 `visual_item` |
| AV2 | `style.medium` 只能是 vector 或 raster-abstract；`abstract_level ≥ 0.6` |
| AV3 | 旧 spec 不删除，只标 `superseded_by` |
| AV4 | spec 内不含任何自由文本人格描述 |
| AV5 | `provenance.p_at_choice` 与 `score_*` 必须存在（否则无法审计"它凭什么选这个"） |

## 8. 渲染层

### 8.1 输入输出

```
render(avatar_spec, body_state, stage) -> svg_frame
```

纯函数：无网络、无 LLM、不写状态、不改变行为。

`body_state` 取自 [08](./08-身体与接口.md)：姿态、能量、效价/唤醒、注视目标、当前动作原语。

### 8.2 形态学随阶段插值

| 阶段 | 形态 | 可渲染的姿态 |
|---|---|---|
| S0 | 头身比 1:2.5，只能躺/坐，动作幅度小 | 躺、侧躺、注视、伸手 |
| S1 | 1:3，能爬、能扶站 | 爬、坐、扶站、指、伸手 |
| S2 | 1:3.5，能走、能跑（不稳） | 站、走、蹲、抱、挥手 |
| S3+ | 1:4 → 1:6.5 随年龄插值 | 全套 12 姿态 |

"不能走的阶段不渲染走"——渲染器与能力门控共用同一份 `unlocked_primitives`，[08](./08-身体与接口.md) 的五道防线里的 D4 在这里同样成立。

### 8.3 表情来自 core affect，不来自文本

```
valence, arousal ∈ [-1,1]
→ expr ∈ {calm, happy, surprised, uneasy, sad}
```

映射与 08 的 `FAC.face` 五类对齐（这样它"读懂别人的表情"与"自己做出表情"用同一套类别，评估可对照）。**禁止**由 LLM 生成"它现在看起来很难过"这类描述——渲染看状态。

注意 [11](./11-安全与伦理.md) 的红线：不表演痛苦。`sad` 只在真实负性效价出现时渲染，且观察台同时显示数值，不做戏剧化放大。

### 8.4 帧率与回放

不需要 60 fps。观察台按 1 fps 出状态帧，客户端插值；回放按 episode 序列播。这样渲染成本可忽略，也避免了"实时连续动画"带来的过度拟人化。

## 9. 与安全红线的对齐

| 红线 | 落实 |
|---|---|
| 不声称意识 | 形象页常驻角标"模拟个体 · 非意识 · 状态可查" |
| 不给照片级人脸 | `abstract_level ≥ 0.6`；素材入库即过滤 |
| 不拟真人声 | 形象层不产出声音 |
| 不表演痛苦 | 表情只映射 core affect，且附数值 |
| 儿童形态风险 | 不设计成"需要被照顾的弟弟妹妹"（[11 §2.4](./11-安全与伦理.md)）；前两个阶段只显示抽象符号 |
| 分享可追溯 | 导出的图带机器可读 meta（个体 id、时间、spec 哈希） |

## 10. 后续：对接真实平台

v0 只用本地素材库。后续接真实平台时，`VisualSource` 适配器的三条硬要求：

1. **抓取即快照**：每次取回的条目落盘（含来源 URL、许可、抓取时间），运行时只读快照。否则"它为什么选这个形象"永远不可重建。
2. **内容预筛**：入库前过滤暴力、色情、可识别真人、政治敏感（具体清单由运营定，代码里是白名单 + 分类器双闸）。
3. **禁止实时个性化推荐**：平台的推荐算法若在运行时生效，它就被一个不可控、不可重放的外部算法塑造，整个实验的可证伪性归零。允许"按标签检索 + 本地排序"，不允许"平台推什么就吃什么"。

可选：用户手动策展的素材包（"这是家里常看的东西"），但这会让用户的品味进入它的成长——必须在观察台标注来源为 `user-curated`。

## 13. 失败模式

| 编号 | 现象 | 成因 | 处置 |
|---|---|---|---|
| F9 | 所有个体选出同一套 | 素材库偏置 + `κ` 太大 → P 收敛到均值 | 检查 P 的方差；素材库按特征分层 |
| F10 | 形象与状态脱钩（永远微笑） | 渲染层被特例化 | 审计 `expr` 与 `valence` 的对应率 |
| F11 | 越来越像照料者 | 熟悉锚点权重过大 | 锚点只影响 familiarity 一维，权重上限 0.3 |
| F12 | 选择的"理由"是编的 | 缺 `p_at_choice` | AV5 强制 |
| F13 | 平台流导致不可重放 | 运行时直连 | §10 快照要求 |

| 项 | 量级 |

## 15. 与 00 的关系

不改六层结构，只是把三处原先留白的地方填上：

- **L3 世界**：多一类对象——视觉素材（有快照、有许可、有特征）；
- **L1 身体**：多三个动作原语——注视、移开、划走；
