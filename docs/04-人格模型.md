# 04 人格模型

> 一句话：人格不是一段描述，而是一组**会被行为改写、又反过来选择行为**的参数；它的真实性由"过去越来越难被重写"来保证。

本文展开 [00-核心设计约定](./00-核心设计约定.md) §4。所有参数是 v0 初值，`config/personality.yaml` 可调，但**调参必须记账**（改了什么、为什么、对哪个指标有预期影响）。

---

## 1. 为什么是四层而不是一层

常见做法是给 agent 写一段人设提示词（"你是一个内向、谨慎、好奇的 7 岁孩子"）。这有三个致命问题：

1. **不可证伪**：行为与描述不一致时，无法判断是人设没生效还是模型没遵守。
2. **不可漂移**：人设是常量，经历无法改写它，所以永远长不大。
3. **可被自述污染**：模型会为了"符合人设"而表演，而不是因为状态而行为。

所以人格必须分层，层与层之间是**因果关系**，不是并列的描述：

```
气质（出生采样，不变） ──映射──▶ 特质（会漂移）
      │                              │
      │                              ├──▶ 行为倾向（选择什么情境、怎么反应）
      │                              │            │
      │                              │            ▼
      │                              │      行为日志（客观记录）
      │                              │            │
      │                              │            ▼
      │                              └──── 行为投影 B̄（每周结算）
      │                                           │
      ▼                                           ▼
   适应性特征（目标/策略/角色/价值观）◀── 巩固 ──▶ 特质漂移
      │
      ▼
   自我叙事（分章自传，改写频率最低）
```

**因果方向**：气质 → 特质 → 行为 → 日志 → 投影 → 特质。闭环让"人是自己选择的结果"成为机制，而不是一句鸡汤。

## 2. 气质：个体差异的唯一合法来源

### 2.1 为什么必须随机

如果气质可以被人为设定，那"这个个体为什么是这样"就退化成"设计者想要它这样"，项目就变成了角色扮演。**个体的独特性必须有一份不可解释的初始噪声。**

出生时从四维正态分布采样（截断到 [-1,1]，`seed = hash(个体ID + 出生时间)` 保证可复现）：

| 维度 | 符号 | 含义 | 分布 | 高端的表现 | 低端的表现 |
|---|---|---|---|---|---|
| 寻求新奇 | S | 对新刺激的接近倾向 | N(0, 0.6) | 主动扑向新东西，快速厌倦 | 只碰熟悉的，新东西先观察 |
| 负性情绪 | NA | 威胁/挫折的反应强度 | N(0, 0.6) | 大声哭、恢复慢 | 轻微反应、快速平复 |
| 努力控制 | EC | 抑制冲动、维持目标 | N(0, 0.6) | 能等、能坚持 | 冲动、易被打断 |
| 亲和 | AF | 对人接近的基线 | N(0, 0.6) | 主动贴近、注视人脸 | 独处更舒适 |

### 2.2 气质不是特质

气质是**反应性参数**，只影响三件事，终生不直接改：

1. **评价阈值**：新刺激被判定为"新奇/威胁"的阈值（S、NA）；
2. **抑制增益**：冲动行为被抑制的概率（EC）；
3. **社会接近基线**：对他人接近的初始概率（AF）。

它不直接产生"我是个外向的人"这样的句子——那是叙事层的事。

### 2.3 气质的映射到初始特质

出生时（S0 第一天）一次性映射：

```
O0 = 0.6·S + 0.2·EC + ε
C0 = 0.8·EC − 0.2·NA + ε
E0 = 0.7·AF + 0.3·S + ε
A0 = 0.7·AF − 0.3·NA + ε
N0 = 0.8·NA − 0.2·EC + ε
ε ~ N(0, 0.05), 结果 clip 到 [-1,1]
```

注意 N0 与神经质同向：负性情绪高的婴儿，初始神经质就高。这是"天生难养"的数学版本。

## 3. 特质：表示、观测、漂移

### 3.1 表示

`T = [O, C, E, A, N] ∈ [-1, 1]^5`，浮点，每周更新一次，落盘为 `state/traits.jsonl`（追加式历史，永不覆盖）。

### 3.2 行为投影 B̄：从行为反推特质

**这是整个模型最关键的一步。** 如果特质由模型自述更新（"我今天很外向"），人格就变成了自我美化。所以 B̄ 必须由**外部可观测的行为统计**算出。

每周对每维特质取若干指标 `x_{j,k} ∈ [0,1]`（比率或频次），用规范常数 `(μ0, σ0)` 标准化：

```
b_{j,k} = tanh((x_{j,k} − μ0_{j,k}) / σ0_{j,k})
B̄_j = Σ_k w_{j,k} · b_{j,k} / Σ_k w_{j,k}          # w 为指标权重，缺测则重归一
```

指标表（v0）：

| 特质 | 指标 | 定义 | μ0 | σ0 | w |
|---|---|---|---|---|---|
| O | 新对象接触率 | 首次接触的对象数 / 可接触对象数 | 0.30 | 0.15 | 1.0 |
| O | 活动多样性 | 活动类别的归一化熵 | 0.45 | 0.20 | 0.8 |
| O | 跨类别尝试 | 进入未去过区域的次数 / 天 | 0.20 | 0.15 | 0.6 |
| C | 计划完成率 | 完成 / 发起的自主计划 | 0.45 | 0.25 | 1.2 |
| C | 坚持时长 | 单次活动持续分钟数的中位数 | 4.0 | 2.0 | 1.0 |
| C | 秩序偏好 | 归位/排序动作占比 | 0.15 | 0.10 | 0.6 |
| E | 社交发起率 | 主动发起互动次数 / 清醒小时 | 0.30 | 0.20 | 1.2 |
| E | 发声量 | 每秒发声时长占比 | 0.10 | 0.08 | 1.0 |
| E | 活动强度 | 动作原语的位移/力度加权和 | 0.35 | 0.20 | 0.8 |
| A | 亲社会占比 | 分享/帮助/安抚 / 社会动作总数 | 0.25 | 0.15 | 1.2 |
| A | 让步率 | 冲突中让步次数 / 冲突次数 | 0.40 | 0.20 | 1.0 |
| A | 安抚频率 | 对他人负性信号的回应次数 / 天 | 0.20 | 0.15 | 0.8 |
| N | 威胁评价率 | 判定为威胁的 episode 占比 | 0.20 | 0.12 | 1.2 |
| N | 挫折恢复 | 负性事件后回到基线的分钟数（取负） | 8.0 | 4.0 | 1.0 |
| N | 安抚寻求 | 负性事件后主动接近照料的频率 | 0.30 | 0.20 | 0.8 |

**缺失处理**：某指标当周无样本（如婴儿期没有"计划"）→ 权重置 0 并重归一；连续两周全缺 → B̄ 取 T 本身（不更新，避免噪声漂移）。

### 3.3 漂移方程

```
T_{w+1} = clip( T_w + η(stage)·(B̄_w − T_w) + λ(stage)·(μ(stage) − T_w) + ξ , −1, 1 )

η = { S0: 0.12, S1: 0.10, S2: 0.09, S3: 0.06, S4: 0.04, S5: 0.02, S6: 0.01 }
λ = { S0: 0,    S1: 0,    S2: 0.020, S3: 0.025, S4: 0.020, S5: 0.015, S6: 0.010 }
ξ ~ N(0, 0.01)     # 个体内噪声：制造非单调，避免变成一阶低通滤波器
```

#### 成熟向量 μ：为什么漂移需要一个方向

只有 η 项时，特质收敛到"这个个体当下环境的平均行为"——那是一个收敛器，不是成长。人长大还有方向：A、C 随年龄上升，N 下降（Roberts, Walton & Viechtbauer 2006 的 maturity principle）。所以加一个**弱引力**：

```
μ(stage) = { O: 0, C: +0.15→+0.30, E: 0, A: +0.20→+0.40, N: −0.15→−0.30 }   # S2 起线性插值到 S6
```

`λ` 比 `η` 小一个数量级，保证它只提供方向、不覆盖经历：同样跑一年，η 能让特质移动约 0.9 个标准差，λ 只能移动约 0.2。若个体的实际行为（B̄）与 μ 方向相反，η 项会赢——**这正是要的**：环境可以逆着成熟方向塑造人格，但需要持续的压力。

"成熟"因此是统计趋势而非强制路径：λ 小、噪声在、个体经历各异，所以有些个体的 N 终生偏高。这不是 bug，是真实存在的个体差异。

#### 为什么是每周而不是每天：日结的 B̄ 方差太大，特质会变成对噪声的追随；月结又会让"一次重大经历"来不及留下痕迹。一周约 30–50 个 episode，统计量刚好可用。

**为什么 η 单调下降**：这是"性格越来越难改"的全部来源。S0–S2 的可塑性是 S5–S6 的 5–10 倍，于是早期经历有复利效应，晚期经历只能微调。这也解释了为什么干预越早越划算。

### 3.4 目标稳定性

30 日重测相关（同一份行为测验）目标：S1 期 0.45–0.60，S3 期 0.60–0.75，S6 期 0.75–0.85。
低于区间 = 人格在乱漂（模型有病）；高于区间 = 经历没起作用（模型是死的）。见 [10-评估与观测](./10-评估与观测.md)。

## 4. 对应原则：特质如何自我强化，又如何被打破

### 4.1 正反馈

情境选择由 T 决定（见 §5 的 softmax），所以 B̄ 与 T 天然正相关，特质被自己的选择强化。这就是 Roberts 等人的 corresponsive principle：**人格塑造经历，经历又塑造人格。**

数学上：若不施加反例，`T_w` 收敛到该个体"习性环境"下的不动点，且收敛速度随 η 下降而变慢——即经历越多，越像自己。

### 4.2 打破的条件（形式化）

特质转向只在**同时满足**下列三条时发生：

1. **期望违背**：`PE = |outcome − expected| > θ_PE`（θ_PE = 1.5σ，σ 为该情境的历史预测误差）；
2. **可控**：该结果被归因为自己的动作（`agency > 0.6`，由"同一动作重复是否复现结果"估计）；
3. **正向**：结果的效价优于期望（对"变好"的违背才改变倾向；"变坏"的违背通常只增加回避，不改变特质）。

否则，异常 episode 被**同化**吸收：

```
w_e = 1 / (1 + PE)          # 违背越大，越不参与 B̄ 的计算
flag_e = "schema_violation" # 但写入图式违背日志，供巩固阶段累积
```

累积的 `schema_violation` 达到阈值（同类情境 3 次）才升级为**顺应**候选，进入夜间的图式重建。这条"先同化、后顺应"的顺序，是皮亚杰机制在工程上的对应物：**人不是一遇到反例就改，而是先把它解释掉；解释不掉才改。**

### 4.3 一个必须承认的偏差

真实人类的气质与经历是**互相选择**的（孩子会主动挑选与自己气质匹配的环境），我们只能近似。简化后果：我们可能低估"环境强制改变人格"的难度。缓解办法是在 S4 之后引入"被安排的环境"（上学、同伴群体），这些情境**不随个体偏好变化**，从而提供外部约束。见 [03-发育阶段与里程碑](./03-发育阶段与里程碑.md)。

## 5. 特质如何进入决策（不能只当标签）

特质通过三个通道影响行为，缺一不可：

1. **注意/评价**：`appraisal.threat = sigmoid(a0 + a1·N + a2·NA + a3·历史威胁率 − a4·安全线索)`
   → 高 N 的个体把同样的模糊刺激评价为更危险，于是选择回避。这一步让 N 影响"看到什么"。
2. **动作选择**：softmax 打分里加特质偏置
   ```
   score(a) = Σ_d w_d·affordance_d(a)
            + β_E·social_gain(a) + β_O·novelty(a)
            + β_C·plan_consistency(a) + β_A·other_benefit(a)
            − β_N·risk(a)
   ```
3. **执行阈值**：高 N 降低"开始一个探索动作"的阈值（更犹豫）；高 EC 提高"打断当前动作"的成本（更能坚持）。

**硬约束（D-05，来自 10-eval）**：`bias_t` 必须是 `T` 的函数，每个 episode 由当前特质现算，且必须通过两条检验：

- 冻结 `T` → 行为分布不变；
- 改动 `T` → 行为分布必须按预期方向移动。

若 `bias` 写成常量、或从提示词读取人格描述，特质就退化成一个仅供展示的仪表盘：指标全部好看，因果为零。这一条列入 13 的不变量 I11，并由 10 的消融实验 E5 检验。

**禁止**：把"我是外向的人"这类句子放进提示词。提示词里只允许出现**当前状态**（数值）和**当前情境**，不允许出现**人格描述**。人格描述只存在于观察台（给人看）。

理由：一旦人格描述进入提示词，模型就会表演它；而表演会污染行为日志，进而污染 B̄，形成"自我实现的角色扮演"。这是本项目最大的作弊通道。

## 6. 适应性特征

特质是"倾向"，适应性特征是"具体怎么办"。四类：

| 类别 | 例子 | 受特质约束的方式 |
|---|---|---|
| 目标 | "把积木搭到 5 层" | 高 C 才可能形成长期目标；低 C 只有即时目标 |
| 应对策略 | "遇到陌生人先躲到妈妈身后" | 由 N、AF 与依恋类型共同决定 |
| 角色 | "在家里是安静的那个" | 由关系史与家庭结构决定 |
| 价值观 | "说谎不好" | 由规范内化的代价史决定（见 07） |

适应性特征**可写、可改**，但修改必须由巩固阶段产生（不能由对话直接写入）。它们落盘为 `state/adaptations.jsonl`。

## 7. 自我叙事：身份的唯一权威文本

### 7.1 结构

自传分章，每章包含：

```yaml
chapter_id: ch-003
period: 2026-11-01 .. 2027-02-28
title: "我学会了走路，也学会了等妈妈"
who_i_am: "一个会自己走到窗边看外面的人"
world: "外面有鸟，鸟会飞走；妈妈会回来"
relationships: {妈妈: "她总是回来", 陌生人: "要抱紧"}
unresolved: ["为什么影子会跟着我"]
evidence: [ep-10231, ep-10987, ...]   # 必须可追溯到事件
```

### 7.2 改写规则（防止过去被随意重写）

1. **低频**：仅在阶段转换、重大关系变化、或 `schema_violation` 累积超阈值时改写；其余时间只追加事件，不改章节。
2. **可追溯**：每章的每个断言必须引用至少一个 episode id；巩固阶段校验引用是否还存在（被遗忘的事件不能支撑断言）。
3. **一致性压力**：新章必须与旧章相洽。冲突时只有两个出口：
   - **降权**：该记忆被标记为"可能记错了"，权重下调（人不总是相信自己）；
   - **改写自我**：承认"我变了"。代价是接下来 1–2 周 **ξ 放大 3 倍、η 临时上调**（身份危机期间行为不稳，且更易被新经历改变）。
4. **不可删章**：旧章只能被标记 `superseded_by`，永久保留。这是 A3（不可逆优先）在叙事层的落实。

### 7.3 叙事的作用（否则就只是一份文档）

叙事必须在决策中起作用，否则就是装饰。三个接入点：

- **预期生成**：遇到新情境时，先从叙事里检索"世界是什么样的"，作为预期的先验；
- **自我一致性成本**：做出与 `who_i_am` 冲突的行为时，增加一个小的内部代价（降低该动作概率），除非情境压力足够大；
- **向人解释**：观察台/对话中，它用叙事解释"我为什么这么做"——这是给人看的，不参与决策。

## 8. 个体差异从哪里来（可分解、可检验）

| 来源 | 机制 | 预期贡献（90 日） |
|---|---|---|
| 气质 | 出生采样 | 初始差异的 60–80%，随时间下降到 30–50% |
| 经历 | 早期依恋、重大事件、环境结构 | 随时间上升，主导中期差异 |
| 噪声 | ξ、随机情境 | 10–20%，制造不可预测性 |
| 测量误差 | 行为投影的采样误差 | 5–10% |

可检验预测：**同气质、不同早期经历的两个个体，在 90 日后应出现可被盲测区分的差异**（见 10 的双生子实验）。如果区分不出来，说明经历通道是假的。

## 9. 反模式清单（每一条都会让人格变成表演）

| 反模式 | 后果 | 正确做法 |
|---|---|---|
| 人格描述进提示词 | 模型表演人格，污染行为日志 | 只注入数值状态与情境 |
| 特质由模型自评更新 | 自我美化，越来越"理想化" | 只由行为投影更新 |
| 每天重写自传 | 过去可被抹掉，永远长不大 | 低频改写 + 不可删章 |
| 全量历史摘要喂入 | 等价于没有记忆 | 巩固 + 检索预算 |
| 情绪由模型命名后驱动行为 | 情绪变成文案 | 先有效价/唤醒，再命名（命名仅用于报告） |
| 用 prompt 控制年龄段 | 婴儿说着成人话 | 身体层门控（见 08） |
| 特质只用于展示 | 人格与行为脱钩 | 三个通道（注意/选择/阈值）必须都接 |

## 10. 参数总表（v0）

| 参数 | 值 | 含义 | 调整影响 |
|---|---|---|---|
| `η(S0..S6)` | .12/.10/.09/.06/.04/.02/.01 | 周可塑性 | 越大越易变 |
| `λ(S0..S6)` | 0/0/.020/.025/.020/.015/.010 | 成熟引力 | 越大越"顺着长大" |
| `μ` | A/C +0.20~0.40，N −0.15~−0.30 | 成熟向量（S2 起） | 决定"往哪长" |
| `ξ` | 0.01（危机期 0.03） | 特质噪声 | 越大越不可预测 |
| `θ_PE` | 1.5σ | 期望违背阈值 | 越小越易被反例改变 |
| `agency` 阈值 | 0.6 | 可控性判定 | 越高越难归因于自己 |
| 图式顺应阈值 | 同类违背 3 次 | 同化→顺应 | 越大越固执 |
| 自传改写上限 | 每阶段 3 次 | 叙事稳定度 | 越大越易"重新做人" |
