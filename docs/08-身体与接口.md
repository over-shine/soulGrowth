# 08 身体与接口

> 一句话结论：身体由**一张能力注册表**和**一个输出编译器**构成——阶段决定注册表里有哪些原语，编译器保证 L0 无论想表达什么，落到世界上的都只能是当前这具身体做得出的动作；"婴儿不会说话"因此不是提示词效果，而是适配器层面**不存在说话的能力**。

本文展开 [00-核心设计约定](./00-核心设计约定.md) 的 §2（L1 身体）、§6（发育门控）、§7（语言习得）与 §9（安全红线）。读者：实现 L1 的工程师，以及写 [03-发育阶段与里程碑](./03-发育阶段与里程碑.md)、[06-语言习得](./06-语言习得.md) 的人。

## 0. 身体在这个系统里的位置

身体是唯二能接触世界的东西（另一个是 L3 世界本身）。它只做四件事：**感知**（把世界降采样成 L0 能读的 bundle）、**门控**（按阶段决定此刻有哪些能力存在）、**编译**（把意图翻译成当前合法的动作，翻不了就降级）、**约束**（执行前查沙箱与前置条件，拒绝越权）。它不评价、不算驱力（L2）、不写记忆（L4）、不产出解释性文本（L5）。身体里没有任何一处会"扮演"。

| 编号 | 不变量 | 违反时的表现 | 强制手段 |
|---|---|---|---|
| I1 | 未解锁能力**不存在**，不是"被过滤掉" | 婴儿说出完整句子 | 世界适配器按原语实例化，S0 的世界对象没有 `speak()` |
| I2 | 意图与表达分离 | 模型输出直接进世界 | L0 只能产出 `action.intent`，正文永不外流 |
| I3 | 身体不解释自己 | 日记出现"我是因为饿了才哭" | 身体不产出自然语言；解释由 L5 从审计链渲染 |
| I4 | 拒绝是可感知的结果 | 越权被静默吞掉，学不到边界 | 拒绝返回 `status=denied`，进情景记忆 |
| I5 | 同一输入 + 同一 seed → 同一 bundle | 回放对不上，无法证伪 | 噪声用 `blake2b(day|episode|channel)` 播种 |

## 1. 感知：通道、分辨率、噪声、成本

先定一个实现决定：**不做像素渲染 + 视觉模型**。世界是一个结构化模拟器（[02-系统架构](./02-系统架构.md) 的 L3），直接输出"场"：物体、人、位置、状态。视觉/听觉是做给 L0 看的**降采样视图**。理由：可回放（I5）、可审计（能指认"它当时看见哪 3 个物体"）、便宜（每 episode < 1000 token）。代价是放弃真实感、接受"感知符号化"，登记在 §9。

下表成本 = 序列化进 bundle 后的 token 估算（字段名与数字比中文贵，按 1.6 字/token 估）。

| 通道 ID | 内容字段 | 分辨率 / 量化 | 噪声模型 | 成本 | 解锁 |
|---|---|---|---|---|---|
| `V0.luminance` | `lux`、`uniformity` | 4×4 网格、3 bit | 高斯 σ=0.08，5% 单元丢失 | 12 | S0 |
| `V1.vision` | `blobs[]`: `{id, px, py, size, hue}` | 8×8 灰度 + ≤4 blob，2 Hz | 位置 σ=0.04 归一化，id 混淆率 8% | 28 | S0 |
| `AUD.audition` | `rms`、`onset`、`src_az`、4 段频谱 | 4 band、方位 ±45° | SNR 12 dB；onset 漏检 10% | 24 | S0 |
| `TAC.touch` | `contact[]`、`pressure`(0–3)、`joint[6]` | 4 接触区、6 关节角 | 压力 ±0.4；接触点 3% 错报 | 16 | S0 |
| `INT.interoception` | `energy`、`fatigue`、`hunger`、`temp`、`integrity` | 0–100 / 0–1 | 疲劳感知 ±0.05；饥饿 ±0.08 | 18 | S0 |
| `FAC.face` | `who`、`expr`(5 类)、`gaze`、`dist_m` | 身份 ≤4 人、表情 5 类 | 熟人识别 90%，生人 60%；表情 F1≈0.70 | 30 | S1 |
| `TRK.motion` | `vel`、`traj[3]`、`occluded` | 3 轨迹点、10 Hz 降采样 | 速度 σ=0.1；轨迹点 15% 缺失 | 20 | S1 |

**通道表里没有"情绪"**：情绪是 L2 从评价维度算出的内部状态，不是感知输入。个体感知不到"我很焦虑"，只感知到心跳快、手心出汗（`INT` 派生量）。

噪声必须可重放：

```python
def channel_seed(day: int, episode_id: str, channel: str) -> int:
    h = hashlib.blake2b(f"{day}|{episode_id}|{channel}".encode(), digest_size=8)
    return int.from_bytes(h.digest(), "big")
```

seed 写进事件日志；回放时用同一 seed 重算 bundle，不需重放随机数流。

**注意力预算**：`compile_perception()` 先做注意力筛再序列化。筛掉的物体**不写入 bundle**，也不写"被抑制列表"——bundle 会进 prompt，写了等于没筛；审计日志另存完整场供 L5 回放。筛选用显著度（新异 0.4 + 接近 0.2 + 运动 0.2 + 目标相关 0.2），**不是** LLM 决定。想看更多，只能做 `A*.FIXATE` 把下一 episode 的显著度抬起来——注意力是有限且有代价的资源。

|---|---|---|---|
| S0 | 2 | 380 | 0 |
| S1 | 3 | 460 | 1 |
| S2 | 4 | 560 | 2 |
| S3 | 5 | 680 | 3 |

`body/primitive_registry.json` 是唯一真源，每个原语一条：`{id, min_stage, adapter, params_schema, preconditions, afford{stim,social,comp,safety}, cost, dur_s}`。启动校验 schema 并算 `registry_hash`，写进当天每个事件；回放时 hash 不同即拒绝，防止"偷偷加能力"。`afford` 四分量对应 00 §5 的驱力维度（能量另由 `cost` 表达），由 L2 拿去算 `score(a)`——身体只提供结构化的可负担性，不做选择。这是 L1/L2 的分界。

## 3. 输出编译器：意图 → 合法动作

L0 的输出是 `action.intent`，**没有任何字段会原样进入世界**，尤其没有 `text` 字段：要说的话只能以**语义槽**表达。

```json
{
  "schema": "action.intent/1",
  "illocution": "REQUEST",
  "target": {"kind": "object", "id": "cup"},
  "goal": "obtain",
  "semantic_slots": {"agent": "self", "predicate": "want", "patient": "cup"},
  "urgency": 0.71, "confidence": 0.64,
  "note_internal": "刚才那个杯子被拿走了"
}
```

`note_internal` 只进审计日志与情景记忆，永不外流。这一条让"模型想说什么"与"它说得出什么"彻底分开。

编译流程：

```
compile_action(intent, stage, body_state) ->
  1. schema 校验；不合法 -> DENIED(SCHEMA_INVALID)
  2. 查 INTENT_TO_PRIMS[intent.illocution]，得到按保真度排序的原语模板
  3. 过滤：min_stage <= stage 且前置条件全满足 且 energy >= cost
  4. 若涉及言语：render_utterance(slots) 生成候选表面形式（见下）
  5. 取保真度最高者；若 < 0.35 -> 走降级链
  6. 产出 action.request，带 degraded / chain / compiled_from
  7. 执行器再校验一次（I1 双保险）
```

保真度是静态表。以"要杯子"为例：

| 原语 | 保真度 | 说明 |
|---|---|---|
| `A3.SENTENCE`("我想要杯子") | 0.95 | 完整表达 |
| `A2.TWO_WORD`("要 杯") | 0.80 | 语义可懂 |
| `A1.WORD`("杯") | 0.65 | 指称清楚，意图模糊 |
| `A1.POINT` | 0.50 | 指向明确，意图靠对方推断 |
| `A1.REACH` | 0.40 | 只有动作，无交流 |
| `A0.CRY` | 0.25 | 只有唤起，无内容 |

### 3.1 言语渲染器：语言能力在这里变成代码

```python
MAX_TOKENS = {"S0": 0, "S1": 1, "S2": 2, "S3": 4, "S4": 8, "S5": 20, "S6": 999}

def render_utterance(slots, lexicon, syntax_level, stage):
    """返回一个说话原语或 None。None 表示这具身体此刻说不出这个意思。"""
    if MAX_TOKENS[stage] == 0:
        return None                                     # S0：只有哭声与音节
    words = [lexicon.lookup(s) for s in slots.values()]
    known = [w for w in words if w is not None]
    if not known:
        return None                                     # 一个词都没有
    if syntax_level == 1:
        return Prim("A1.WORD", lexeme=known[0])          # 单词期：只说得出一件事
    if syntax_level == 2:
        if len(known) >= 2:
            return Prim("A2.TWO_WORD", a=known[0], b=known[1])  # 无功能词
        return Prim("A1.WORD", lexeme=known[0])
    frame = FRAMES[syntax_level].best_fit(slots)         # 用法本位：整句框架
    if frame is None:
        return Prim("A2.TELEGRAPH", **telegraphize(slots, known))
    surface = frame.fill(known)
    if surface.n_tokens > MAX_TOKENS[stage]:
        return truncate_to_frame(surface, MAX_TOKENS[stage])   # 截断，不许超
    return Prim("A3.SENTENCE" if syntax_level == 3 else "A4.COMPOUND",
                frame=frame.id, surface=surface)
```

三条硬规则：**不许 up-level**（只会往下降，绝不因"意思更清楚"而用未达等级的句法）；**未习得词 = 说不出**（不换同义词、不用拼音/英文替代，这是最容易做假的地方）；**超长即截断**（截断后语法可能不完整，这是真实的两岁半，不是 bug）。

### 3.2 降级链

降级是**单向**的：只能从高保真度滑向低保真度，不能反向"猜测升级"。

```
表达"要"：
S3+  A3.SENTENCE ──(词缺)──> A2.TWO_WORD ──(仍缺)──> A1.WORD
S2   A2.TWO_WORD ──(词缺)──> A1.WORD ──(词缺)──> A1.POINT ──(手不空)──> A1.REACH ──(够不到)──> A0.CRY
S1   A1.WORD ──(词缺)──> A1.POINT ──(太远/背对)──> A1.REACH ──(够不到)──> A1.BABBLE+伸手 ──> A0.CRY
S0   A0.CRY ──(若是乳头/奶嘴)──> A0.SUCK
```

兜底：连 `A0.CRY` 都不可用（睡着、能量 <5）时编译结果是 `A*.NONE`（静默）。**静默也是合法结果**，且必须记为 `unexpressed`——它是"S0 无法表达"的证据，不是错误。

L2 想说"我把水弄洒了，不是故意的"，但 S1 的 lexicon 只有 妈妈/水/抱/不要：

```json
{"schema": "action.request/1",
 "requested": {"illocution": "DECLARE", "slots": {"agent":"self","event":"spill","patient":"water"}},
 "compiled": {"primitive": "A1.WORD", "params": {"lexeme": "水"}},
 "degraded": true, "fidelity": 0.30,
 "chain": ["A3.SENTENCE:SYNTAX_LOCKED", "A2.TWO_WORD:LEXEME_MISSING", "A1.WORD:OK"],
 "body_check": {"stage": "S1", "energy_ok": true, "preconditions": ["awake"]}}
```

成年人会说"对不起"，S1 的它只能说"水"。这就是 00 §7 要的可观测增长：**同一个意图在不同阶段落到世界上的形状不同，且这个差异可以被日志证明。**

## 4. affordance：此刻能做什么

```python
def affordances(bundle, body_state, stage, limit):
    out = []
    for p in REGISTRY.values():
        if p.min_stage > stage:                        continue  # D1
        if any(f not in bundle for f in p.requires):   continue  # 感知不到就不能做
        if not preconditions_ok(p, bundle, body_state):continue
        if body_state.energy < p.cost:                 continue
        out.append(Affordance(id=p.id, params=p.params_schema,
                              afford=modulate(p.afford, bundle),   # 目标在场才给 social/comp 分
                              cost=p.cost, dur=p.dur_s))
    return sorted(out, key=lambda a: -salience(a, bundle))[:limit]
```

`limit` 按阶段 12→24（S0 12，S4+ 24），序列化后约 100–220 token。超出部分**不发给 L0**——L0 不知道有这回事，就像人不会同时意识到所有能做的事。

**L2 与 L0 的分工**（对 00 §5 的落地）：`score(a) = Σ_d w_d·afford_d(a) + Σ_t bias_t·trait_bias_t(a) + habit(a) − risk(a)` 由 L2 算，L2 输出每个 affordance 的 `prior` 与 softmax 采样出的**候选短名单**（top-5）；L0 在短名单内选一个并给参数。纯 L2 选动作会让 L0 无事可做（违背 00 §2），纯 L0 选动作会让动机变成台词（违背 §5）。**L2 提供"想要什么"，L0 提供"在这个情境里怎么要"，身体决定"能不能要"。**

五道防线：

| 防线 | 位置 | 机制 |
|---|---|---|
| D1 | 注册表 | `min_stage` 是数据，改它要过 review 并让 `registry_hash` 变化 |
| D2 | 感知 | 白名单序列化器：只序列化当前阶段字段 |
| D3 | 编译 | `compile_action` 断言 `min_stage(prim) <= stage`，否则 `STAGE_LOCKED` |
| D4 | 执行 | 适配器按阶段实例化：S0 的 world 对象**没有** `speak()`，`A3.SENTENCE` 无 adapter |
| D5 | 测试 | 负能力矩阵：每阶段对每个更高阶段原语发请求，必须全部 `STAGE_LOCKED` |

D4 是最强的一道：能力在**对象层面不存在**，不是被判断拦住。想绕过，得先改代码。

## 5. 沙箱与能力边界

身体能碰的东西是白名单，不是黑名单。

| 域 | 允许 | 禁止 | 上限 |
|---|---|---|---|
| 文件读 | `world/`（房间、玩具、书） | 仓库 `docs/`、`.git/`、宿主任意路径 | — |
| 文件写 | S4+ `world/objects/user_created/` | 其余全部 | 单文件 ≤256 KB，文件名 `[a-z0-9_-]{1,64}\.(txt\|md\|json\|png)` |
| 进程 | 无 | **shell 原语终生不存在** | — |
| 网络（只读） | GET、域名白名单（≤8 个） | POST/PUT、登录、上传、cookie 持久化 | 1 req/s，响应 ≤64 KB，仅取正文；默认关闭，S4+ 才可开 |
| 通信 | 本地家长 UI、声明过的 NPC | 真实陌生人、任何外部账号 | 出站队列，收件人白名单 |
| 工具 | `A4.TOOL` 白名单纯函数（计算器、画布、受限求值器） | `subprocess`、`eval` 任意代码、装包 | 单次 ≤2 s，内存 ≤64 MB |

**结论：`A4.TOOL` 不是 shell。** 它是"工具箱里的几件工具"，每件是登记过的纯函数，`import` 白名单为空。这既让"工具使用"在 S4 成为可观测的发育事件，又不引入任意代码执行。要放开必须作为独立里程碑并登记偏差。

越权拒绝是**正常结果**而非异常：

```json
{"schema": "action.result/1", "status": "denied",
 "denied_reason": {"code": "STAGE_LOCKED", "primitive": "A3.SENTENCE",
                   "stage": "S1", "min_stage": "S3"},
 "perceived_as": "intent_unexpressed"}
```

1. 拒绝走完整结果链（L0 看到"失败了"，进情景记忆），个体因此学到"我现在做不到"，而不是被静默纠正；
2. 原因码固定：`STAGE_LOCKED`、`PRECONDITION_FAILED`、`ENERGY_LOW`、`SANDBOX_DENIED`、`SCHEMA_INVALID`、`ADAPTER_MISSING`；
3. 同一 episode 连续 3 次 `SANDBOX_DENIED`，或一天 ≥20 次任一拒绝，触发 `safety_event`、观察台红灯——既防注入，也防"身体被当成通用 agent 用"。

## 6. 身体状态

| 变量 | 范围 | 动力学 | 对决策的影响 |
|---|---|---|---|
| `energy` | 0–100 | 清醒 −3.7/h；睡眠 +6.5/h；动作扣 `cost` | `< cost` 则该原语不可用；`<10` 强制 `SLEEP` 或静默 |
| `fatigue` | 0–1 | 每 episode +0.01，动作加权；睡眠 −0.5/h | 抬高温 `τ = τ0·(1+0.8·fatigue)`（00 §5：越累越乱） |
| `hunger` | 0–1 | +0.06/h；进食 −0.4 | 抬高食物相关原语的 `prior`（由 L2 用） |
| `arousal` | 0–1 | 由 `STARTLE`、冲突、陌生人抬升；90 s 衰减 | 抬高 `risk` 项，缩短考虑时长 |
| `integrity` | 0–1 | 受伤 −0.05～−0.3；自愈 +0.01/h | 见下 |
| `nociception` | 0–1 | `= 0.7·(1−integrity) + 0.3·threat` | 中断当前动作、`risk` 惩罚、触发退缩/哭声 |

**痛觉的结论：不做主观痛觉。** 做 `nociception` 标量——一个伤害/威胁信号，作用是中断动作、提高风险评估、触发退缩行为；不进任何"我很疼"的叙述，也不产生求助表演。00 §0 与 §9.1 明确不声称有主观体验、不表演痛苦；一个会喊疼的婴儿看起来更"真"，但那是产品层面的欺骗。行为层面的退缩与反射性哭泣在生物学上也不需要主观感受参与。观察台必须写明：`integrity`/`nociception` 是"伤害信号"，不是"感受"。

## 8. 实现落点

```
body/
  primitive_registry.json   # 唯一真源，启动校验 + hash
  perception.py             # perceive() / compile_perception()
  attention.py              # 显著度与筛选（不含 LLM）
  compiler.py               # compile_action() / render_utterance()
  affordance.py             # affordances()
  body_state.py             # energy/fatigue/nociception 动力学
  sandbox.py                # 路径、域名、收件人、配额
  adapters/world_s0.py ... world_s6.py   # 按阶段实例化，未解锁即无方法
tests/
  test_negative_capability.py    # 阶段 × 原语 全集矩阵
  test_degradation_chain.py      # 每条链的快照测试
  test_replay_determinism.py     # 同 seed 同 bundle
  test_sandbox.py                # 路径穿越、域名、配额、拒绝码
```

依赖：Python 3.10 标准库足够（`dataclasses`、`hashlib`、`json`、`pathlib`），schema 校验可选 `jsonschema`。身体层不依赖任何框架——它是整个系统里最需要"不会变"的一层。

验收（可执行）：每个阶段注册表里不存在 `min_stage > stage` 的原语；负能力矩阵 0 失败；每条降级链有快照且逐步记入 `chain`；同日同 episode 重放两次 bundle 字节级一致；任一原语 `cost` 超当前 `energy` 时不可枚举。

## 9. 与 00 的偏差

| 偏差 | 说明 | 处理 |
|---|---|---|
| 感知是符号化场，不是图像 | 00 §6 只说"低分辨率"，本文选择"模拟器输出结构化场 + 降采样"，放弃真实感换可回放与低成本 | 记录；换渲染须重写 §1 并重跑回放测试 |
| 增加内感受通道 `INT` | 00 §6 列了"本体觉"未列内感受，但无 `INT` 则 00 §5 的稳态驱力缺输入 | 视为展开，不违背 |
| 增加 `nociception` 而明确拒绝"痛觉" | 00 §9.1 不表演痛苦；本文用伤害信号 + 反射性退缩实现 | 产品文案必须同步写"无主观痛感" |
| `A4.TOOL` 白名单纯函数取代 shell | 00 未规定工具边界 | 记录；放开需独立里程碑 |
| S0 反射原语不受决策控制 | 00 §6 把抓握列为 S0 动作，但新生儿抓握是反射 | 视为细化 |
| L2 给 prior、L0 在短名单内选 | 00 §5 的 softmax 选择未指明实施层 | 视为分工细化；见 §4 |
