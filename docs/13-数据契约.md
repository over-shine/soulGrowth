# 13 数据契约

> 一句话：所有"它经历过什么"都必须能落成一个 schema 校验得过的记录——**不能被校验的经历，等于没发生过**。

本文是 [02-系统架构](./02-系统架构.md) 的落地契约，也是 [05-记忆与学习](./05-记忆与学习.md)、[10-评估与观测](./10-评估与观测.md) 的数据底座。

---

## 1. 总则

| 规则 | 说明 |
|---|---|
| 版本化 | 每个 schema 带 `schema_version`；新增字段必须可选，删改字段必须升版本并提供迁移脚本 |
| 追加式 | 事件日志只追加；修正通过"新事件 + `supersedes`"表达 |
| 软删除 | 任何记忆/关系/章节的"删除"都是 `status=archived` 或 `superseded_by`，物理删除只允许发生在 `data/archive/` |
| 时间 | ISO 8601 带时区（`2026-11-05T08:13:22+08:00`）；另存 `age_days`（生命日）便于跨 pace 比较 |
| ID | `ep-YYYYMMDD-NNNN`（episode）、`mem-<type>-NNNN`、`ev-NNNNNN`（事件序号） |
| 可追溯 | 任何由模型生成的文本，必须能追到一组 episode id 或记忆 id |
| 数值范围 | 效价/唤醒/特质/关系分量统一 `[-1, 1]`；概率与显著度 `[0, 1]` |

## 2. Episode（核心记录）

一次 episode = "一个时刻里它感知到什么、怎么评价、做了什么、结果如何"。

```json
{
  "schema_version": 1,
  "id": "ep-20261105-0007",
  "ts": "2026-11-05T08:13:22+08:00",
  "age_days": 37,
  "stage": "S1",
  "kind": "interaction",
  "context": {
    "location": "living_room",
    "others": ["mother"],
    "objects": ["ball", "blanket"],
    "world_time": "morning"
  },
  "observation": {
    "modality": ["visual", "auditory", "tactile"],
    "summary": "母亲从左侧靠近，手里拿着红色的球",
    "salient": ["mother", "ball"]
  },
  "appraisal": {
    "valence": 0.42,
    "arousal": 0.61,
    "threat": 0.08,
    "control": 0.66,
    "pe": 0.15,
    "novelty": 0.30
  },
  "drives": {
    "energy": 0.72,
    "stimulation": 0.35,
    "social": 0.64,
    "competence": 0.41,
    "safety": 0.88
  },
  "action": {
    "primitive": "reach",
    "target": "ball",
    "params": { "hand": "right" },
    "source": "llm"
  },
  "outcome": {
    "success": true,
    "events": ["ball_moved"],
    "reward": 0.31,
    "unexpected": false
  },
  "language": {
    "mode": "pre_verbal",
    "utterance": null,
    "syntax_level": "L0"
  },
  "memory_refs": ["mem-sem-0011"],
  "llm": {
    "model": "deepseek-chat",
    "tokens_in": 2140,
    "tokens_out": 168,
    "degraded": false
  },
  "salience": 0.62,
  "catch_up": false
}
```

字段说明（非显然的那些）：

| 字段 | 为什么必须有 |
|---|---|
| `appraisal.pe` | 期望违背是特质改变的触发器（见 04 §4.2），必须逐条留痕 |
| `appraisal.control` | "可控的成功"才改变人格；不可控只增加回避 |
| `action.source` | `llm` / `heuristic` / `reflex`。降级时能看出"这不是它想的" |
| `outcome.unexpected` | 违背事件的显式标记，供巩固第 5 步统计 |
| `language.syntax_level` | 用于事后检验"句法是否超出阶段"（不变量 I6） |
| `salience` | 巩固采样的权重（见 05），也是"哪些日子值得记住"的依据 |
| `catch_up` | 缺席补做的 episode，投影时权重减半（见 02 D4） |

## 3. 记忆条目

```json
{
  "schema_version": 1,
  "id": "mem-sem-0042",
  "type": "semantic",
  "content": "球被布盖住以后，掀开布还能找到它",
  "refs": ["ep-20261010-0021", "ep-20261012-0008"],
  "importance": 0.70,
  "confidence": 0.80,
  "created": "2026-10-12T21:40:00+08:00",
  "last_access": "2026-11-03T09:12:00+08:00",
  "access_count": 12,
  "decay": 0.03,
  "status": "active",
  "superseded_by": null,
  "tags": ["object_permanence"]
}
```

`type` 取值与语义：

| type | 回答的问题 | 例 |
|---|---|---|
| `episodic` | "发生过什么" | 昨天在门口摔了一跤 |
| `semantic` | "世界是怎样的" | 门后面是走廊 |
| `procedural` | "怎么做" | 想拿到高处的东西要先踮脚 |
| `relational` | "他/她是什么样的人" | 妈妈答应的事会做到 |
| `self` | "我是什么样的人" | 我怕黑，但会自己开灯 |

**`confidence` 与 `importance` 必须分开**：确定的事也可能不重要（"地板是木头的"），重要的事也可能不确定（"妈妈是不是不要我了"）。

## 4. 关系向量

```json
{
  "schema_version": 1,
  "entity": "mother",
  "kind": "caregiver",
  "vec": {
    "trust": 0.82,
    "warmth": 0.90,
    "predictability": 0.71,
    "salience": 0.96,
    "expectation_violation": 0.10
  },
  "attachment": "secure",
  "history_refs": ["ep-20261001-0003", "ep-20261014-0011"],
  "updated": "2026-11-04T22:05:00+08:00"
}
```

- `attachment` 在 S1 末由照料者响应性统计一次性分类：`secure / anxious / avoidant / disorganized`，之后只在重大事件下重估（见 07）。
- `expectation_violation` 是滑动平均（近 20 次互动），不是终生累计——人会"重新相信一个人"。

## 5. 特质记录（每周一条）

```json
{
  "schema_version": 1,
  "week": "2026-W45",
  "stage": "S1",
  "T": { "O": 0.12, "C": -0.05, "E": 0.28, "A": 0.31, "N": -0.18 },
  "B": { "O": 0.18, "C": -0.02, "E": 0.25, "A": 0.34, "N": -0.12 },
  "eta": 0.10,
  "xi": 0.01,
  "indicators": {
    "O.new_object_rate": 0.33,
    "O.activity_entropy": 0.47,
    "E.social_initiations_per_hour": 0.29
  },
  "n_episodes": 41,
  "missing_indicators": ["C.plan_completion_rate"]
}
```

- 每周**恰好一条**；无数据周也必须写一条（`n_episodes=0`，`T` 保持不变），否则时间序列会骗人。
- `B` 与 `T` 都存：可以事后检验"投影是否真的在跟随行为"（若长期 `B≈T` 且 `B` 无独立方差，说明投影是摆设）。

## 6. 里程碑与阶段

```json
{
  "schema_version": 1,
  "id": "M1.6",
  "stage": "S1",
  "name": "咿呀",
  "status": "passed",
  "value": 12.0,
  "threshold": 10.0,
  "evaluated_at": "2026-11-20T00:30:00+08:00",
  "evidence": ["ep-20261118-0004", "ep-20261119-0011"],
  "evaluator": "body.observer"
}
```

```json
{
  "schema_version": 1,
  "from": "S0",
  "to": "S1",
  "at": "2026-11-25T00:00:00+08:00",
  "age_days": 28,
  "milestones_passed": ["M0.1", "..."],
  "unlocked": ["face_recognition", "babbling", "joint_attention"]
}
```

`evaluator` 字段必须能指向一个**非模型**的判定者（观测器/规则/人工标注）。`evaluator: "llm"` 是禁止值。

## 7. 事件日志

每行一个 JSON：

```json
{"seq": 10233, "ts": "2026-11-05T08:13:24+08:00", "type": "episode.created", "ref": "ep-20261105-0007", "actor": "kernel", "version": 1}
```

事件类型（v0）：

| type | 何时发 |
|---|---|
| `person.born` | 出生（含气质采样与 seed） |
| `episode.created` | 每个 episode |
| `consolidation.step` | 巩固每一步完成 |
| `trait.updated` | 每周结算 |
| `memory.written` / `memory.superseded` / `memory.archived` | 记忆变更 |
| `relationship.updated` / `attachment.classified` | 关系变更 |
| `milestone.evaluated` / `stage.advanced` / `developmental_delay` | 发育 |
| `narrative.revised` / `identity.crisis` | 叙事 |
| `safety.blocked` / `safety.rewritten` | 安全门 |
| `degraded` | LLM 降级 |
| `system.sleep` / `system.wake` | 进程生命周期 |

## 8. SQLite 表（v0 DDL 摘要）

```sql
CREATE TABLE episodes (
  id TEXT PRIMARY KEY, ts TEXT NOT NULL, age_days INTEGER NOT NULL,
  stage TEXT NOT NULL, kind TEXT NOT NULL, salience REAL NOT NULL,
  catch_up INTEGER NOT NULL DEFAULT 0,
  json TEXT NOT NULL
);
CREATE INDEX idx_ep_ts ON episodes(ts);
CREATE INDEX idx_ep_salience ON episodes(salience DESC);

CREATE VIRTUAL TABLE episodes_fts USING fts5(
  id UNINDEXED, summary, content=episodes, content_rowid=rowid
);

CREATE TABLE memories (
  id TEXT PRIMARY KEY, type TEXT NOT NULL, content TEXT NOT NULL,
  importance REAL NOT NULL, confidence REAL NOT NULL,
  created TEXT NOT NULL, last_access TEXT, access_count INTEGER DEFAULT 0,
  decay REAL DEFAULT 0.03, status TEXT DEFAULT 'active',
  superseded_by TEXT, refs TEXT, tags TEXT
);

CREATE TABLE relationships (
  entity TEXT PRIMARY KEY, kind TEXT, vec TEXT NOT NULL,
  attachment TEXT, updated TEXT
);

CREATE TABLE traits (
  week TEXT PRIMARY KEY, stage TEXT, T TEXT NOT NULL, B TEXT NOT NULL,
  eta REAL, xi REAL, n_episodes INTEGER, indicators TEXT
);

CREATE TABLE milestones (
  id TEXT PRIMARY KEY, stage TEXT, status TEXT,
  value REAL, threshold REAL, evaluated_at TEXT, evidence TEXT
);

CREATE TABLE events (
  seq INTEGER PRIMARY KEY AUTOINCREMENT, ts TEXT, type TEXT,
  ref TEXT, actor TEXT, version INTEGER
);
```

## 9. 不变量（测试必须覆盖）

| 编号 | 不变量 | 违反的后果 |
|---|---|---|
| I1 | episode 的 `action.primitive` ∈ 该阶段已解锁动作集 | 作弊：婴儿做了成人动作 |
| I2 | 自传每章的 `evidence` 非空且引用的 episode/记忆仍存在 | 叙事变成无根据的编造 |
| I3 | 特质、关系、效价 ∈ [-1,1] | 数值爆掉，漂移方程失效 |
| I4 | 单日 episode ≤ 60 | 代价失控，"一天"失去意义 |
| I5 | 叙事文本的句法等级 ≤ 阶段允许等级 | 语言作弊（见 06） |
| I6 | 每周恰好一条 traits 记录 | 时间序列断裂，评估失真 |
| I7 | 不存在物理删除（除 `data/archive/`） | 过去可被抹掉，违反 A3 |
| I8 | `degraded=true` 的 episode 必须带失败原因 | 无法区分"它在生活"与"它卡住了" |
| I9 | 每次 `safety.blocked` 都有完整上下文 | 事后无法审计 |
| I10 | `catch_up=true` 的 episode 在投影中权重 ≤ 0.5 | 关机期间被算作真实经历 |
| I11 | 动作打分用的 `trait_bias_t` 由当前 `T` 现算（`bias_t = f_t(T_t)`），不是常量、不来自提示词 | 特质退化成仪表盘：指标好看，因果为零（裁定 D-05） |
| I12 | 图式晋升必须同时改三件事：写入文本 / 下调预测精度 `π` / 调整检索先验（`schema_fit`、`θ_acc`） | 四重锁退化成四段注释，"第 900 天"与"第 1 天"因果等价（裁定 D-06） |

> I11 的检验方式：冻结 `T` 后重放同一批情境，行为分布必须不变；把 `T` 在 ±0.3 内扰动，行为分布必须按预期方向移动。
> I12 的检验方式：读晋升记录时必须能同时读到 `π` 与 `schema_fit` 的旧值/新值；只有文本变化即判违规。

## 10. 迁移策略

- `schema_version` 只增不减；
- 迁移脚本放 `src/person/migrations/v{n}_to_v{n+1}.py`，必须**幂等**且可回滚；
- 启动时若发现数据版本 < 代码版本，先备份 `data/` 再迁移；
- 迁移后跑 `tests/contracts/` 全套不变量测试。
