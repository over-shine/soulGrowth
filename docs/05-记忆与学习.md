> 一句话结论：成长不是"记得更多"，而是"越来越难被改写"——它只发生在夜里的巩固中，白天只提供采样。

## 0. 论点：成长在巩固，不在对话

### 0.1 一个反例

设 agent 每天"检索全部历史 + 重写一份摘要"来维持自我。第 1 天与第 900 天它拥有的是同一类对象：对全部历史的最优压缩。于是 `S = f(H; q)` 只依赖当前 query；对任意旧事件 e，总存在一个 q 使 e 的权重趋近 0，也存在一个 q 使其趋近 1；因此不存在"这段历史已经定了"的状态。

这种 agent 每天都是同一个人——不是因为它稳定，而是因为它**可塑**：任何时候都能被一段足够长的对话重新解释成另一个人。00 §A3 称之为"反成长"。

### 0.2 不可逆性的形式条件

要让"成长"可判定，必须存在一个不随 query 变化的单调量 `M_t = (π, strength, depth)`：`π_t ∈ (0,1]` 剩余可塑性，**单调不增**；`strength` 已晋升结构的证据强度，**单调不减**（只能 supersede，不能清零）；`depth` 自传章数。条件：对任意重写算子 T 与任意时刻 t，

```
M( f( T(H≤t); q ) )  ⪰  M( f( H≤t; q ) )        # 逐分量不小于
```

即任何一次"重新理解过去"都不能减少已经结构化的东西，只能增加，或在原结构上标注"被取代"。这不是哲学，是可测的：给 agent 一段新经历，检查它能否在库里**删除**一个已晋升的语义节点——答案必须是"不能"。

### 0.3 四重锁

| 锁 | 机制 | 锁住什么 | 若失锁 |
|---|---|---|---|
| 可塑性 π↓ | 晋升阈值随年龄升高，改写成年代价上升 | 新结构的形成速度 | π 恒定 → 每天可以重新开始 |
| 遗忘 R(t) | 与 query 无关的时间衰减，只降权不删 | 旧事件的**可及性** | 不遗忘 → 预算无限、噪声与信号等权 |
| 图式同化 | 新经验写入前先被旧结构折射 | **写入通道本身** | 不同化 → 每件事同样新鲜，性格不结晶 |
| 叙事一致性 | 高层章节低频改写、须与既有章相洽 | 自我的**解释权** | 不锁 → 自我叙事随对话漂移 |

四条锁是四个方向不同的力：π 管"进来的速度"，遗忘管"出去的流量"，同化管"进门的形状"，叙事管"楼顶的承重"。缺一条，其余三条都能被绕过。

### 0.4 为什么对话内学习不够

1. **上下文是 FIFO，不是时间。** 窗口内 token 等距；检索让 3 天前与 300 天前在同一平面竞争。没有"更旧"，就没有"被时间检验过"。
2. **改写无代价且不可复现。** 同一段历史 summarize 两次得到两份自我，都无法审计，也无法回滚到"它当时为什么这么想"。
3. **没有单调量。** 不产生 `M_t`，"它更成熟了"就不可证伪——正是 00 §0 的成功判据要排除的东西。

结论：对话只产生"这一次的行为"；只有跨 episode 的有损压缩才产生"这一次之后的这个人"。**白天采样，夜晚推断。**

## 1. 记忆分层

分层的首要目的不是整洁，是**写权限隔离**：若谁都能写语义记忆，A1（权重不变、外部状态可审计）就退化成"prompt 里塞了什么就是什么"。层的划分沿用 Tulving(1972) 的情景/语义之分，但另加 M3 程序与 M4 自传两块。

| 层 | 名称 | 存什么 | 时间尺度 | 容量量级 |
|---|---|---|---|---|
| M0 | 工作记忆 | 当前 episode 的感知缓冲 + 检索结果 + 目标栈 | 单 episode（秒–分） | ≤1200 token |
| M1 | 情景 | 一次闭环：谁、在哪、期望、发生、结果、情绪 | 终生，append-only | 1.5 万条/年 |
| M2 | 语义 | 事实、规则、实体属性、图式（槽 + 默认值） | 终生，只增不减 | 10³–10⁴ |
| M3 | 程序 | 动作序列 × 上下文 → 成功率 / 时延 / 参数 | 终生，衰减退化 | 10²–10³ |
| M4 | 自传 | 分章叙事（我是谁 / 世界 / 我和谁） | 阶段级 | ≤12 章 |

M0 不落盘（除日志）：00 §10 要求"任何'它记得'都必须能在磁盘上指出来"，而 M0 不是"记得"，是"正在看"。

### 1.1 写权限矩阵

`写` = 可直接创建/修改；`申` = 只能提交写入申请（由 L4 决定是否落盘）；`读` = 可检索；`—` = 不可。

| 层 | L0 基质 | L1 身体/感知 | L2 引擎 | 巩固器 | 人类 |
|---|---|---|---|---|---|
| M0 | 读 | 写 | 读 | — | 读 |
| M1 | — | 申 | 申 | 写（只加注） | 读 |
| M2 | — | — | 申（期望/违背） | 写 | 读 + 干预 |
| M3 | — | 申（结果） | 读 | 写 | 读 |
| M4 | — | — | — | 写（受配额） | 读 + 审批 |

1. **L0 对记忆零写权限。** 它只看到检索结果，看不到数据库。"我觉得该记住这个"不构成写入，最多成为 `write_request`，由规则裁决。
2. **M1 append-only。** 情景不可编辑，只能追加"复述记录"与"同化标注"。这让审计链成立：第 300 天回看第 3 天，看到的是当时写的，不是后来改的。
3. **M2/M4 只能 supersede。** 旧节点保留，新节点带 `supersedes` 指针。直接对应 00 §A3 与 §9.3"可回放"。

**各层各答一个问句**：M1 情景答"那天发生了什么"，必须带 appraisal（新奇/目标一致/可控/归因），显著度由它算（§3.1）且**不由模型自述**；M2 语义答"世界是怎样的"，事实是命题、图式是带默认值的槽结构，只有后者会扭曲知觉（§6）；M3 程序答"怎么做"，不存文本只存统计量（§7）；M4 自传答"我是谁"，是唯一允许"解释"而非"记录"的层，因此最慢。

## 2. 存储与索引

### 2.1 三处账，一个方向

| 介质 | 角色 | 谁写 | 能否反向 |
|---|---|---|---|
| SQLite | 真相：事件、统计、索引、审计 | 引擎 / 巩固器 | 唯一权威 |
| JSON | 结构化定义：schema、图式、章节、配置 | 巩固器（原子替换） | 权威（定义类） |
| Markdown | 人读：日记、周报、章节渲染 | 渲染器（模板） | **只出不进** |

最容易被做坏的是 Markdown：一旦允许"人改 Markdown → 回写数据库"，就出现两个真相源，审计链断裂。所以规定：**Markdown 是投影，丢失可重建；重建脚本必须存在，且 nightly 用 hash 校验。**

### 2.2 SQLite schema 草案

## 3. 检索打分

### 3.1 四项 + 一项偏置

```
score(m | q, t) = w_r·recency + w_s·salience + w_m·match + w_h·rehearsal
                + β·schema_fit − λ·redundancy

recency   = exp(−Δt_days / τ_layer)
salience  = clip(0.35|v| + 0.25·a + 0.20·nov + 0.20·goal, 0, 1)
match     = clip((cos(e_q, e_m) − 0.30) / 0.70, 0, 1)
rehearsal = ln(1 + n_recall) / ln(1 + N_max),   N_max = 8
schema_fit= max over active schemas of slot-match ratio ∈ [0,1]
```

| 权重 | 值 | 依据 |
|---|---|---|
| w_r | 0.20 | 时间衰减（Anderson & Schooler 的 recency 幂律的指数近似） |
| w_s | 0.25 | 情绪显著性优先于相关性 |
| w_m | 0.30 | 相关性最强，但**不是唯一** |
| w_h | 0.10 | 复述效应 |
| β | 0.15 | 图式偏置（同化的技术实现，见上） |

`τ_layer`：M1 = 14 天、M3 = 60 天、M2 = 120 天、M4 = 730 天。τ 越大，"旧"越不构成劣势——语义与自传本来就该慢。

**schema_fit 是故意的偏置。** β > 0 意味着：**已有图式会让与它一致的记忆更容易被想起**。这是 00 §A3"图式一旦形成就会扭曲新知觉（同化先于顺应）"在检索层的实现。它是有代价的偏差，因此必须可审计：`retrievals` 表分别记 `match` 与 `schema_fit`，把 β 置 0 重算一遍即可证明偏差存在（§9 E2 的对照组）。

### 3.2 预算（硬上限）与检索主循环

| 阶段 | 候选池 | 注入条数 | token 上限 | 额外注入 |
|---|---|---|---|---|
| S0 | 4 | 2 | 200 | 无 |
| S1 | 8 | 3 | 400 | 1 条图式 |
| S2 | 12 | 4 | 700 | 1 图式 + 1 程序 |
| S3 | 16 | 5 | 1000 | 1 图式 + 1 段自传 |
| S4+ | 16 | 5 | 1200 | 同上 |

预算不是优化项，是**语义条件**：若预算随历史线性增长，"检索"就退化为"压缩全部历史"，0.1 的反例立刻复活。

```python
def retrieve(q, ctx, budget):
    pool = []
    for layer, k in [(M1, 12), (M2, 3), (M4, 1)]:
        for m in index.search(layer, q.emb, k=k):        # 向量 + FTS 混合
            m.score = score(m, q, t=now, beta=BETA)
            pool.append(m)
    pool = mmr(pool, lam=0.7, pick=budget.top_k)        # argmax score−0.7·max cos(·,S)；无 MMR 则 5 条注入里 4 条是同一事件的近重复
    inject(pool, max_tokens=budget.tokens); log_retrieval(pool)
    for m in pool:
        if m.injected: m.n_recall += 1; m.last_access = now
        else:          m.miss_count += 1                # 只降权，§5.3
    return pool
```

`miss_count` 不是噪声：一个事件在被需要时没被想起，本身就是"它在变淡"的证据，必须记账。

## 4. 夜间巩固：成长真正发生的地方

### 4.1 为什么是这里

白天的每次 episode 只改变 M0 与 M1 的一行。若故事到此结束，这个个体只是一个日志系统——它的"自我"是检索器的函数（0.1 的反例）。**巩固是唯一能改变"检索器本身"的算子**：它改 π、改 strength、改 schema、改叙事。成长发生在夜里，且每晚只有一次机会（生物对照：巩固依赖睡眠中的重放，McGaugh 2000；Wilson & McNaughton 1994）。

### 4.2 流水线

| # | 阶段 | 输入 | 输出 | 用 LLM |
|---|---|---|---|---|
| 0 | 封账 | 当日 episodes | 冻结列表、算 salience | 否 |
| 1 | 聚类 | 当日 + 近 7 日未巩固 + 近 3 日被复述的旧片段 | clusters（dist=0.25, 2–12 条） | 否（嵌入） |
| 2 | 模式提取 | 每 cluster | 泛化候选（必须引用 ≥2 个 episode id） | 是（小模型） |
| 3 | 校验 | 候选 + 既有 M2 | fit / conflict / novel | 是（小模型，批量） |
| 4 | 图式候选 | 校验结果 | 新节点或 violation 记录 | 否（规则） |
| 5 | 晋升 | 候选 + 证据 | M2 新节点 / 强化旧节点 | 否（规则） |
| 6 | 程序更新 | 动作-结果对 | M3 统计更新 | 否 |
| 7 | 叙事检查 | 累积 violations | 章节改写请求 | 是（大模型，低频） |
| 8 | 遗忘结算 | 全库 | R 值、状态迁移 | 否 |
| 9 | 渲染 | 全库 | Markdown 日记 / 周报 | 否（模板） |

LLM 只出现在 2、3、7，且都是**提议者不是决定者**：晋升由规则（5）裁决。这是防止模型把"我觉得这很重要"写成事实的唯一办法。

### 4.3 伪代码

```python
def nightly_consolidate(day):
    eps = freeze(episodes.where(consolidated_at is None))
    units = cluster(eps + episodes.rehearsed_since(day-3), dist=0.25, min_size=2)
    promoted, rejected = [], []
    for u in units:
        cand = extract_pattern(u, model=SMALL)          # 必须返回 source_ep_ids
        if len(distinct_days(cand.source_ep_ids)) < 2:
            rejected.append((cand, "single-day")); continue   # 一天不算模式
        verdict = verify(cand, existing=active_m2(), model=SMALL)
        if verdict == "conflict":
            record_violation(cand, u); continue         # §6.3，不写入
        n, w = len(cand.source_ep_ids), sum(e.salience for e in eps_of(cand))
        N = max(3, ceil(3 + 4*(1 - pi(day))))           # §4.4
        if verdict == "fit":
            strengthen_schema(verdict.schema_id, n, w); continue
        if n >= N and w >= 0.8*N and unresolved_conflicts(cand) == 0:
            promoted.append(promote(cand, confidence=f(w, N)))
        else:
            rejected.append((cand, "insufficient", n, N))
    update_procedures(day); maybe_request_chapter_revision(day)   # §7, §6.4
    settle_forgetting(day); render_markdown(day)                  # §5, 模板 0 token
    audit_log(day, units, promoted, rejected)
```

### 4.4 晋升阈值随年龄上升

```
π_s = {S0:1.00, S1:0.90, S2:0.70, S3:0.50, S4:0.30, S5:0.15, S6:0.05}
π(day) = π_s · exp(−(day − day_s) / 730)            # 阶段内缓慢衰减
N_promote = max(3, ceil(3 + 4·(1 − π)))
confidence = (support_w / N) · (1 − contradict_ratio) · π^0.5
```

由上式，S0–S6 的 `N` 依次为 3/4/5/5/6/7/7。直观含义：**三岁的孩子听两次就学会"猫会抓人"；三十岁的人需要七次。** 这不是能力下降，是结构变重：早期经验便宜地结晶，后期经验必须付出更多证据才能改动已结晶的部分。

### 4.5 一次晋升同时改变三件事

晋升不是"多了一条笔记"，它同时改：**检索先验**（新 schema 进入 `schema_fit`，次日同 query 会召回更多与它一致的记忆）、**顺应阈值**（strength 抬高 `θ_acc`，推翻它需要更多违背）、**可塑性**（全局 `π ← π·(1 − 0.005·min(n_support,5))`，写入 `plasticity_ledger`）。

第三条最容易被忽略：**如果晋升不降低可塑性，个体就会无限形成新图式，等于没有性格。** 00 §4.2 的 η(stage) 只让特质变慢，没让记忆结构变重；本文补上这一环。

## 5. 遗忘

### 5.1 保留概率

```
R(m, t) = exp(−t / S_m)                     # 记作 R = exp(−t/S)；t 为距最后写入的天数

S_m = S_0 · (1 + α·salience) · (1 + β·ln(1 + n_recall)) · κ_emotion · κ_layer
S_0 = 3 天，α = 2.0，β = 0.8
κ_emotion = 1 + 1.5·|valence|               # 情绪事件更黏
κ_layer   = {M1: 1.0, M3: 1.3, M2: 4.0, M4: 20.0}
```

量级（括号内为 `R` 降到 0.5 的天数）：低显著、无复述 S≈3 天（2 天），日常流水；高显著、无复述 S≈9（6 天），第一次打针；高显著、复述 5 次 S≈25（17 天），反复讲起的事；M2 语义节点 S≈12–160，几乎不衰减，衰减只表现为降 `status`。`exp(−t/S)` 取指数而非幂律，是 Ebbinghaus(1885) 曲线的现代参数化，S 就是那条曲线的"记忆强度"。

### 5.2 状态机：只降权，不删除

```
active --R<0.25--> dormant --R<0.05 且 90 天未触及--> cold（只留指针与摘要）
cold --审计/干预--> 可恢复        删除：只允许人类显式操作（00 §9.3 可回放）
```

`dormant` 查得到但默认不注入（降权）；`cold` 只留 `{id, day, embedding, 一句摘要}`，正文进冷存文件；而 `deleted` **不是我们的状态**。遗忘是"想不起来"，不是"没发生过"——这对应 Bjork & Bjork 的存储强度与提取强度分离，也正是 Tulving & Pearlstone(1966) 的"可得性 vs 可及性"，以及 00 §A3 在最低层的落实。

### 5.3 复述与提取失败

```
成功提取：n_recall += 1，S ← S·(1 + 0.15·spacing_ok)
          spacing_ok = 1 if Δt_last ≥ 1 天 else 0      # 集中重复无效
候选但未注入：miss_count += 1，S ← S·0.90，最多 3 次
```

间隔效应是硬要求：**连续两天反复想同一件事，不产生额外记忆强度**（Cepeda et al. 2006）。否则"重要的事"会因每天被检索而永不衰减，遗忘曲线失效。

**遗忘为什么算成长。** 它让检索预算恒定（§3.2），于是"记得"这件事有信息量；它让保留本身成为证据（300 天后仍被想起的事件，比当天被记录 300 次的事件更有分量）；它让 M2 晋升的"支持证据"不是全量可选，而是被时间筛过的幸存者。反过来：**永不遗忘的系统里，"重要"无法定义**，因为所有东西都同等可用。

## 6. 图式动力学

### 6.1 强度

```
strength_{t+1} = clip(strength_t + γ·s_i − δ·c_i, 0, 0.98)
γ = 0.06（每个支持 episode），δ = 0.18（每个矛盾观察），上限 0.98
```

不对称（δ ≈ 3γ）是设计：**坏事比好事更能改写世界模型**。这让"创伤性事件"在机制层成立，而不是修辞。上限取 0.98 而非 1.0：任何图式都必须留一道可推翻的缝。

### 6.2 同化优先

感知进来先匹配图式（Piaget 1952 的同化），命中的槽用默认值填补，**并记下填补了哪些槽**：

```
A(schema, percept) = Σ_j w_j · match(slot_j, percept)
若 A ≥ θ_match = 0.55：assimilate → summary 用默认值补全
                        assimilated = [被填补的槽名]; schema.assimilations += 1
```

`percept_raw` 与 `summary` 分开存（§2.2），于是"图式扭曲"成为可测数字：`distortion(e) = 1 − cos(emb(e.summary), emb(e.percept_raw))`。这是 Bartlett"记忆是重建不是回放"（1932）的可计算版本，也是 §9 E2 的因变量；Loftus & Palmer(1974) 是同一机制在人类身上最著名的极端案例。没有 `percept_raw`，这个实验做不了，所以那一列的存储成本必须付。

### 6.3 顺应的触发条件

违背强度 `V = clip(|observed − expected| / σ_schema, 0, 3)`，σ_schema 取该图式历史残差的中位数（初期用 0.3 兜底）。

```
S_v = Σ_{未解决 violations, 近 30 天} V_i
θ_acc(π) = 2.5 + 4.0·(1 − π)              # S0 2.5 → S6 6.3
触发顺应 ⟺ S_v ≥ θ_acc ∧ 涉及 ≥3 个不同 episode ∧ 无 pending 冲突
```

```python
def maybe_accommodate(schema, day):
    vs = unresolved_violations(schema, window=30); Sv = sum(v.magnitude for v in vs)
    if Sv < theta_acc(pi(day)): return "assimilate"          # 默认吸收
    if len({v.episode_id for v in vs}) < 3: return "assimilate"
    if (1.0/pi(day) - 1.0) > NARRATIVE_BUDGET: return "defer"  # 越老越贵，攒着
    new = revise_schema(schema, vs)                           # supersedes 旧节点
    return request_identity_crisis(new) if conflicts_with_locked_chapter(new) else new
```

`defer` 不是失败：它把"我解释不了"攒起来，这正是 00 §4.4"身份危机"的燃料。

### 6.4 与自我叙事的接口

00 §4.4 规定叙事冲突只有两个出口——降低该记忆权重，或改写自我，后者须付出"一段时间行为不稳"的代价。本文变成四条可执行路径：

| 路径 | 触发 | 实现 | 代价 |
|---|---|---|---|
| 降权 | 冲突但 `S_v < θ_acc` | 该 episode 的 `narrative_weight × 0.6` | 无 |
| 改写 | `S_v ≥ θ_acc` 且配额未用尽 | 新章 supersedes 旧章 | `π −= 0.02`（写 `plasticity_ledger`）+ 7 天行为抖动 |
| 加注 | 配额用尽 | 旧章只追加 `注（第 N 天）` | `narrative_dissonance += 1` |
| 升级 | `narrative_dissonance > 5` | 观察台报"叙事撕裂" | 需人类介入，不自动改 |

配额：每阶段 1–3 次（00 §4.4）。配额用尽后是**加注而不是重写**——因为"我改不了自己"本身也是一种真实状态。

## 7. 程序记忆与技能

条目是 `(上下文指纹, 动作序列, 参数) → 结果分布`，指纹 = 嵌入量化到 64 维，**不存文本**——文本可以被下一次对话重新解释，统计量不能。

### 7.1 成功率：带遗忘的 Beta

```
每次使用：α ← λ·α + 1[success]，β ← λ·β + 1[¬success]，λ = 0.97
p̂ = α/(α + β)，n_eff = α + β − 2
```

λ < 1 意味着**它估的是"现在会不会"，不是"历史平均会不会"**。6 岁学会骑车、16 岁再骑的人，p̂ 不应被 6 岁那 200 次成功主导。

### 7.2 练习曲线（幂律）

```
p(n) = p_∞ + (p_0 − p_∞)·n^(−μ)，  时延 L(n) = L_1·n^(−0.30)
p_∞ = 0.55 + 0.25·EC_norm        # 努力控制高的个体天花板更高
μ  = 0.30 ~ 0.45                 # 简单动作取小，复杂动作取大
```

用幂律（Newell & Rosenbloom 1981）而非指数：进展集中在前几次，之后长尾。积累 10 次练习后拟合一次，`μ` 与 `p_∞` 写回 M3——所以"这孩子学东西快"是个可拟合参数，不是形容词。

### 7.3 迁移、退化与习惯

```
迁移增益：g = κ·exp(−d/δ)，κ = 0.30，δ = 0.5，d = 1 − cos(ctx, ctx′)
退化：p_t = p_floor + (p_0 − p_floor)·exp(−t/S_proc)
      p_floor = 0.20，S_proc = 21·(1 + 0.5·ln(1 + n_practice)) 天
habit 成立 ⟺ p̂ ≥ 0.85 ∧ n_eff ≥ 10 ∧ 最近 30 天用过 → habit(a) = +0.5·p̂（00 §5）
```

退化地板 0.20 而非 0："学会了就忘不干净"——与情景记忆的 `cold` 同构。习惯一旦成立，**不再经过 softmax 的完整比较**，这是"性格表现为不假思索"的机制；危险点对称存在，坏习惯同样会固化，所以 M3 需要人工清除通道（观察台标 `extinguish`，留痕）。

## 8. 对现有工作的批判

### 8.1 Generative Agents（Park et al., 2023）

memory stream 存全部观察，按 recency / importance / relevance 加权检索，定期 reflection 生成更高层总结。工程上正确，发育上不成立：

- 流是**全量且无损**的，没有任何条目会因为"太久没想起"而降权；
- reflection 是对全流的再一次压缩，**两次 reflection 可以给出互相矛盾的自我**，且不留下"哪次是错的"；
- 没有 `M_t`，所以"这个 agent 第 30 天更成熟了"不可证伪。

### 8.2 MemGPT（Packer et al., 2023）

把上下文当主存、外部存储当磁盘，靠模型自己调函数换入换出。它解决**容量**，不解决**发育**：

- 换出不是遗忘：被换出的内容随时可无损换回，过去永不衰减；
- 谁进主存由模型自己决定，缺少外部不可逆约束（对比本文：晋升由规则裁决，模型只是提议者）；
- 没有泛化算子：分页不产生语义，只产生"更省 token 的同一份历史"。

### 8.3 CoALA（Sumers et al., 2024）

把语言 agent 的认知架构分为 working / episodic / semantic / procedural，分类学上正确——本文 M0–M4 直接借它。但它是**名词表不是动力学**：它说该有什么模块，不说模块之间如何随时间相互改写。分类正确不等于会长大。

### 8.4 三条可直接对照的差异

| # | 维度 | 它们 | 本文 | 如何观测 |
|---|---|---|---|---|
| 1 | 检索是否受既有结构偏置 | 检索 = f(query) | 检索 = f(query, schema, π) | 把 β 置 0 重算，命中集必须变化（E2） |
| 2 | 记忆是否被降权 / 移出 | 无（全量，或可无损换回） | 有，且只降权不删 | 30 天后低显著事件的注入率必须显著低于高显著 |
| 3 | 巩固产物是否改变系统本身 | 不（只是新文本） | 是（改检索先验、改 θ_acc、降 π） | 删掉 M2+M4 后行为分布必须显著偏移（E3） |

**结论**：它们的 agent 在第 30 天与第 1 天的差别只是"存储更长"，人格仍是初始 prompt 的后验。本文的目标是让"第 30 天的它"在因果上**不能**回到第 1 天。

## 9. 可测试性

### E1 延迟回忆：30 天后还记不记得

- 设计：第 D 天植入 4 个受控事件（2 高显著 × 2 低显著），各 1 个带强制复述；在 D+7 / 30 / 90 用同一组线索检索。
- 指标：注入率（是否进 top-5）、rank、由数据反推的 `R̂`。预测：注入率单调下降；高显著 > 低显著；复述组衰减更慢；拟合的 S 与 §5.1 预测在 ±30% 内。
- **证伪条件**：若注入率与显著度、复述无关，或 30 天后仍 100% 注入——说明系统实际"没忘"，即 0.1 的反例。注意：**100% 的回忆率不是优点，是缺陷的证据。**

### E2 图式扭曲

- 设计：先 10 天建立图式（"吃饭要用勺子"）；第 11 天呈现歧义场景（用叉子吃米饭）；比较 `summary` 与 `percept_raw`。
- 指标：`distortion`、`assimilated` 槽数、去掉 β 后检索命中集的变化率。预测：S2–S3 期 distortion 显著 > 0；出现足够多违背后，distortion 先升（顺应前的挣扎）后降（新图式接管）。
- **证伪条件**：distortion 恒为 0 → 没有图式，分层是装饰；或顺应后 distortion 不降 → 学习没发生。

### E3 记忆消融

- 设计：第 90 天做 A/B。对照正常；实验组保留 M1、清空 M2+M3+M4（或随机置换）。跑 10 个**未见过**的情境，比较动作分布。
- 指标：动作分布的 Jensen–Shannon 散度、行为投影 `B̄` 的偏移。预测：JSD 显著 > 0——记忆是因果的，不是装饰。
- **证伪条件**：JSD ≈ 0，即行为由基质与当前感知决定、记忆只是日志。此时 00 §0 的成功判据不成立，必须重做设计而不是调参。

三个实验都必须跑在一个**能分别关掉四条锁**的 ablation 面板上：关 π↓、关遗忘、关同化、关叙事锁，看哪条被关掉后 E1–E3 的差异消失。这是"四重锁是否都在承重"的唯一证明。

## 10. token 成本

### 10.1 每日增量（S3+，40 episodes/天）

| 项 | 调用数/天 | 输入 token | 输出 token | 备注 |
|---|---|---|---|---|
| episode 检索（纯数值打分） | 40 | 0 | 0 | 无 LLM，这是设计目标 |
| 检索歧义重排（分数差 <10%） | ≈8 | 7.2k | 1.2k | 小模型 |
| 巩固：聚类 | 6 | 0 | 0 | 嵌入 + 规则 |
| 巩固：模式提取 | 6 | 12k | 2.1k | 每 cluster 约 2k 上下文 |
| 巩固：校验（批量） | 1 | 1.5k | 0.25k | |
| 叙事检查（1/3 天摊薄） | 0.33 | 1.2k | 0.3k | 仅触发时 |
| 遗忘结算 + Markdown 渲染 | — | 0 | 0 | 模板 |
| **合计** | | **≈22k** | **≈3.9k** | |

**分阶段**：S0 ≈1.5k / 0.2k，S1 ≈4k / 0.6k，S2 ≈12k / 2k，S3+ ≈22k / 3.9k，S4+ ≈28k / 5k（输入 / 输出，每天）。

全量检索型 agent 省掉了巩固成本，但每次 episode 都要注入更长的上下文：`8k × 40 = 320k/天`；本文是 `1.2k × 40 + 22k ≈ 70k/天`。**巩固不是开销，它是把"每轮检索成本"换成"一次性压缩成本"的套利**——而这个套利的前提正是遗忘与晋升：省钱和长成人是同一件事。按任意单价 `p_in, p_out` 代入 `月成本 = 30(in·p_in + out·p_out)`；不写具体美元数，因为价格会变，而设计不该依赖它。

## 11. 与 00 的偏差

1. **00 §2 数据流 `结果 → 情景记忆`**：细化为 `结果 → EpisodeComplete 事件 → L4 计算 salience 并落盘`。L1 仍不能直接写记忆（申 ≠ 写），但"salience 由谁算"00 未写，本文定为 L4，并保证不来自模型自述。
2. **00 §4.4 叙事改写"每阶段 1–3 次"**：增加第三条出口"加注"（配额用尽后只追加带日期的注，不重写）。这不是新增改写通道，而是承认"改不动"是真实状态，并用 `narrative_dissonance` 让观察台能报警。
3. **00 §3 只说 Night 是巩固批处理**：补充失败语义——单个 cluster 失败不阻塞整夜；窗口超时则 `partial consolidation` 并记账；**下一夜不得补做超过 1 天的积压**，否则时间被压缩，巩固失去稀缺性。
4. **00 §10 三写（JSON / Markdown / SQLite）**：收窄为 **Markdown 是单向投影，禁止解析回写**；即"三写"实为"两写一渲染"（§2.1）。
5. **00 §A3"可塑性只降不升"**：引入 `intervention:plasticity_boost`（唯一允许 π 上升的接口），须由人类发起、写 `plasticity_ledger`、观察台可见。符合 00 §A3 括号内"人为干预须留痕"。
6. **新增 `cold` 冷存层**：00 未定义归档。cold 只留指针与摘要，**删除只能由人类执行**（依 00 §9.3"可回放"）。
7. **00 §6 阶段表未给 S0 的记忆能力**：本文给 S0 极窄预算（200 token / 2 条），并规定 S0 不形成 `schema`、只有 sensorimotor 程序，以避免与 infantile amnesia 冲突（Madsen & Kim 2016）。[待核] S0 是否应允许极简图式。
