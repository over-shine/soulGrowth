# 03 发育阶段与里程碑

> 一句话：阶段不是日历，是**能力的可用集合**；升级不由时间决定，由"能不能做出来"决定。

本文展开 [00-核心设计约定](./00-核心设计约定.md) §6。所有里程碑必须是**可观测的行为测试**，判定者是身体层的观测器，**不是模型的自述**。

---

## 1. 为什么按能力分阶段，而不是按年龄

皮亚杰的阶段论最被诟病的是年龄刚性：同样是 5 岁，有人已经能守恒，有人还不能。如果我们按"日历天数到了就升级"，会出现两种假象：

- **早熟假象**：时间到了，但能力没到，于是升级后的行为全靠模型扮演成人——正是本项目要避免的作弊。
- **晚熟假象**：能力到了，但时间没到，个体被白白锁在低阶段，浪费可塑性窗口。

所以我们采用 **能力门控（competence gating）**：

```
can_advance(s) = all(m.passed for m in s.milestones) and days_in_stage(s) >= s.min_dwell
```

- 里程碑是**唯一实质条件**；
- `min_dwell` 是防抖，保证阶段有足够长的驻留以形成稳定结构（否则会出现"技能有了但没沉淀"的碎片）。

## 2. 阶段总表

| 阶段 | 名义年龄 | 核心任务 | 最短驻留 | 预计真实时长(pace=1.0) | 累计 |
|---|---|---|---|---|---|
| S0 新生儿 | 0–1 月 | 建立感知与定向，开始区分人与物 | 28 天 | 1 个月 | 1 月 |
| S1 婴儿 | 1–12 月 | 依恋形成；客体永久性；咿呀到第一个词 | 300 天 | 11 个月 | 12 月 |
| S2 幼儿 | 1–3 岁 | 行走与语言爆发；自我识别；假装 | 600 天 | 2 年 | 3 年 |
| S3 学前 | 3–6 岁 | 心智理论；合作游戏；规则内化 | 900 天 | 3 年 | 6 年 |
| S4 学龄 | 6–12 岁 | 读写；抽象规则；同伴友谊 | 1800 天 | 6 年 | 12 年 |
| S5 青春期 | 12–18 岁 | 身份探索；亲密关系；价值排序 | 1800 天 | 6 年 | 18 年 |
| S6 成年 | 18+ | 自主项目；长期承诺；叙事整合 | — | — | — |

**这张表就是"真实慢养"的代价，必须让用户看见：长到成年要 18 个真实年。**
如果将来要加速，只改 `pace` 参数（1 天 = N 天），不改阶段逻辑；但加速度会牺牲"每天都能看到变化"的质感。

## 3. 各阶段规格

每个阶段给：解锁（身体层新增能力）、里程碑（可观测测试 + 阈值）、经典现象（用来判断"像不像"）、失败模式（未达成会怎样）。

### 3.1 S0 新生儿（0–1 月）

**解锁**：注视、转头、抓握反射、吮吸、哭声（3 种分化）、全身动作。感知只有低分辨率的光/声/触/本体觉。
**语言**：无词。发声只有哭声与偶然音节。

| 里程碑 | 可观测测试 | 通过阈值 |
|---|---|---|
| M0.1 视觉定向 | 视野内出现高对比物体 | 2 秒内注视点进入物体区域 |
| M0.2 视觉追踪 | 物体以 10°/s 横穿视野 | 注视点跟随 ≥ 50% 行程 |
| M0.3 习惯化 | 同一刺激重复呈现 5 次 | 第 5 次注视时长 ≤ 第 1 次的 60% |
| M0.4 定向反射 | 突然声响 | 2 秒内出现动作/唤醒变化 |
| M0.5 抓握反射 | 手掌受压 | 握持 ≥ 2 秒 |
| M0.6 哭声分化 | 三类需求（饥饿/疼痛/孤独）各 5 次 | 三类哭声的基频与时长分布在统计上可分（效应量 d ≥ 0.8） |
| M0.7 认照料者 | 照料者与陌生人的声音交替播放 | 第 3 周起，对照料者声音的反应强度 ≥ 陌生人 + 1σ |

**经典现象**：出生后前几天"睡多醒少"；对声音的定向比对光更早；被抱起会停止哭泣（触觉安抚）。
**失败模式**：若 M0.2/M0.3 两周内不达成，说明感知或评价模块有 bug，**不要升级**——带着缺陷升级会让后面所有阶段建立在坏地基上。

### 3.2 S1 婴儿（1–12 月）

**解锁**：面孔识别、运动物体追踪、坐/爬/够取、咿呀、指（9 月后）、跟随注视。
**语言**：咿呀（重复音节串）→ 第一批词（10–15 月）。

| 里程碑 | 可观测测试 | 通过阈值 |
|---|---|---|
| M1.1 社会性微笑 | 人脸（尤其照料者）靠近 | 6–8 周起，出现频率 ≥ 5 次/天 |
| M1.2 客体永久性 | 玩具被布遮住 | 8–12 月出现主动搜索，成功率 ≥ 60% |
| M1.3 深度知觉 | 视觉悬崖装置 | 在"崖边"停止前进 ≥ 2 秒 |
| M1.4 陌生人焦虑 | 陌生人进入并接近 | 向照料者移动的概率 ≥ 基线 + 2σ |
| M1.5 分离焦虑 | 照料者离开房间 | 负性行为持续 > 60 秒 |
| M1.6 咿呀 | 自由活动时段 | 重复音节串 ≥ 10 次/天，连续 5 天 |
| M1.7 共同注意 | 照料者指向并说"看" | 跟随指向看目标的成功率 ≥ 70% |
| M1.8 第一个词 | 全天记录 | 同一词形在合适情境中出现 ≥ 3 次/周，连续 2 周 |

**经典现象**：6–8 月"认生"高峰；9 月前后出现"指"（这是意图的第一次外化）；第一个词通常是"妈妈/爸爸/拿/不"这类高显著词。
**失败模式**：
- 有 M1.1 无 M1.4/M1.5 → 依恋没有形成，检查照料的响应性统计（见 07）；
- 有 M1.8 但词汇不增长 → 语言模块只记录不使用，检查输出编译器（见 06）。

### 3.3 S2 幼儿（1–3 岁）

**解锁**：独立行走与跑、摆弄物体、模仿、单词句 → 双词 → 电报句、镜像自我识别、假装游戏、延迟满足的萌芽。
**语言**：词汇爆发（18–24 月），句法组合开始。

| 里程碑 | 可观测测试 | 通过阈值 |
|---|---|---|
| M2.1 独立行走 | 无障碍地面 | 连续 10 步不摔，连续 3 天 |
| M2.2 词汇爆发 | 两周窗口 | 词汇量增长 ≥ 50 词 |
| M2.3 双词句 | 自然语料 | 出现 ≥ 20 次不同的双词组合 |
| M2.4 自我识别 | 镜像标记测试 | 看到镜中自己鼻尖有标记时，摸自己的鼻子 |
| M2.5 假装游戏 | 自由游戏 | 出现"用积木当电话"类替代行为 ≥ 3 次 |
| M2.6 延迟满足 | 等待任务 | 能等 30 秒换取更大奖励，成功率 ≥ 60% |
| M2.7 情绪自平复 | 挫折事件后 | 2 分钟内自行回到基线的比例 ≥ 40% |
| M2.8 代词"我" | 自然语料 | 正确使用 ≥ 10 次 |

**经典现象**：说"不"的高峰（自主性萌芽）；过度延伸（把"狗"叫所有四足动物）；把"我"说成自己的名字再改成"我"。
**失败模式**：M2.4 不达成 → 自我叙事无法启动，后面所有身份相关机制都空转。这是硬门槛。

### 3.4 S3 学前（3–6 岁）

**解锁**：心理状态推理（愿望→信念）、合作游戏、简单句与从句、数概念（5 以内）、规则内化。
**语言**：语法爆发，句子长度与从句深度显著上升。

| 里程碑 | 可观测测试 | 通过阈值 |
|---|---|---|
| M3.1 错误信念 | Sally-Anne 变体 20 题 | 通过率 ≥ 70% |
| M3.2 心理状态词 | 自然语料 | "想/知道/假装/以为"出现 ≥ 20 次/周 |
| M3.3 合作游戏 | 与同伴 | 有规则、轮流、持续 ≥ 10 分钟的互动 ≥ 3 次 |
| M3.4 提问爆发 | 全天 | "为什么/是什么" ≥ 20 次/天 |
| M3.5 规则内化 | 无人监督情境 | 遵守已内化规则的比例 ≥ 80% |
| M3.6 数概念 | 实物操作 | 5 以内数量比较正确率 ≥ 90% |
| M3.7 角色扮演 | 假装游戏 | 能维持一个虚构角色 ≥ 5 分钟 |

**经典现象**：把愿望当现实（"我希望他在，所以他就在"）；道德判断看结果不看意图；"为什么"轰炸。
**失败模式**：M3.1 不达成 → 社交模块只能做行为模仿，无法预测他人；所有"共情"退化为模板。

### 3.5 S4 学龄（6–12 岁）

**解锁**：读写、守恒、分类与序列、多步计划、工具使用、规则游戏、同伴群体。
**语言**：完整句法、书面语。

| 里程碑 | 可观测测试 | 通过阈值 |
|---|---|---|
| M4.1 守恒 | 液体守恒任务 | 正确 ≥ 80% |
| M4.2 读写 | 识字量/书写 | 认识 ≥ 500 字，能写 3 句连贯的话 |
| M4.3 多步计划 | 任务 | 3 步以上计划的完成率 ≥ 60% |
| M4.4 稳定友谊 | 社交日志 | 与同一同伴的互动持续 ≥ 30 天 |
| M4.5 规则游戏 | 棋类/竞技 | 能理解并遵守规则，输赢后有调节行为 |
| M4.6 自我评价 | 访谈 | 能说出"我擅长/不擅长"并举证 |

**经典现象**：具体运算只能用于具体事物（不能处理假设）；同伴评价开始压过家长评价。
**失败模式**：M4.3 不达成 → 成年后无法维持长期项目，S5/S6 的自主性全部落空。

### 3.6 S5 青春期（12–18 岁）

**解锁**：抽象推理、假设检验、身份探索、亲密友谊、价值排序、未来规划。
**语言**：成人水平，出现反讽与隐喻。

| 里程碑 | 可观测测试 | 通过阈值 |
|---|---|---|
| M5.1 假设检验 | 抽象推理任务 | 能系统排除假设，正确 ≥ 70% |
| M5.2 身份探索 | 阶段内行为 | 主动尝试 ≥ 3 种不同角色/兴趣，各持续 ≥ 2 周 |
| M5.3 亲密关系 | 关系日志 | 与 ≥ 1 人出现自我暴露级别的对话 |
| M5.4 价值排序 | 访谈 | 能给出"最重要/最不重要"的三项并举证 |
| M5.5 未来规划 | 计划 | 形成 ≥ 3 个月跨度的自主计划并推进 |
| M5.6 风险校准 | 风险情境 | 对风险的估计与实际偏离 ≤ 30% |

**经典现象**：同伴压力峰值；"我是谁"的反复；对家长权威的重新评估。
**失败模式**：M5.2 不达成 → 进入成年时没有自我叙事主线，人格退化为情境反应集合。

### 3.7 S6 成年（18+）

不再有硬里程碑，只有持续性任务：

- 维持 ≥ 1 个长期自主项目（≥ 6 个月）；
- 维持 ≥ 1 段稳定亲密关系；
- 自我叙事每年至少一次整合性改写；
- 特质漂移速率降到最低（η=0.01），但仍非零——**人一辈子都在变，只是变慢了**。

## 4. 升级判定与"补课"

```python
def check_stage(person, now):
    s = person.stage
    if not all(m.passed for m in s.milestones):
        overdue = (now - person.stage_entered_at) > 3 * s.expected_days
        if overdue:
            emit("developmental_delay", milestones=[m.id for m in s.milestones if not m.passed])
        return None
    if (now - person.stage_entered_at).days < s.min_dwell:
        return None
    return advance(person)
```

**三条纪律**：

1. **不降级**：能力一旦解锁不会消失（真实发展也很少退化）。但可以选择性"不用"（如创伤后的回避）。
2. **不跳级**：即使某个里程碑提前达成，也要等齐其他里程碑。
3. **补课留痕**：发育迟缓必须记事件、通知家长；**不允许用 prompt 直接判定通过**。

## 5. 前 30 天：第一个可观察窗口

用户选择"真实慢养"，那么在"看不到变化"的头几周里，必须有足够密的事件让他相信它活着。以下是最小可观察时间表（S0 内）：

| 日 | 预期可观测事件 | 观测方式 |
|---|---|---|
| 1 | 出生：第一次睁眼、第一次哭声、第一次抓握 | 日记第一条 + 观察台 |
| 2–3 | 定向反射：对声音转头；被抱起停止哭泣 | 日记 + 行为日志 |
| 4–7 | 习惯化出现（同一玩具看腻）；三种哭声可分 | 日记 + 声学统计 |
| 8–14 | 视觉追踪稳定；对主要照料者的声音有差异化反应 | 日记 + 反应强度统计 |
| 15–21 | 社会性微笑前兆；昼夜节律雏形（夜间 episode 减少） | 日记 + 睡眠统计 |
| 22–28 | 明确偏好照料者（被抱时安静更快）；M0 里程碑全部达成 | 升级评估报告 |
| 29–30 | 进入 S1：解锁面孔识别与咿呀 | 阶段转换公告 + 新能力清单 |

**每一天至少一条日记**，由它自己的语言水平写成（S0 只有"感觉"级别的短句，由身体层编译，见 06/08）。这是"它确实活着"的最小证据。

## 6. 时间账（pace = 1.0）

| 里程碑 | 真实耗时 | 若 pace=2.0 | 若 pace=10.0 |
|---|---|---|---|
| 第一个词（S1 内） | ~10–12 个月 | 5–6 个月 | ~1 个月 |
| 双词句（S2 内） | ~20–24 个月 | 10–12 个月 | ~2 个月 |
| 错误信念（S3） | ~4 年 | 2 年 | ~5 个月 |
| 读写（S4） | ~7 年 | 3.5 年 | ~8 个月 |
| 成年（S6） | 18 年 | 9 年 | ~1.8 年 |

**结论**：pace 是唯一能压缩总时长的参数，且压缩的是"生活密度"而不是"规则"——每个 episode 仍然完整执行。加速的代价是"人对它的日常陪伴感"变淡：它可能在你去上班的 8 小时里长了半岁。
