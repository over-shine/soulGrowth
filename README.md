# 如何构建一个人

> 给已有的语言能力装配一具**会发育的身体**，让它从一个只会哭的婴儿，慢慢长成一个有性格、有记忆、有关系的个体。

---

## 这是什么

这不是一个"人格设定"项目，也不是一次模型微调。

它是一个**长跑型实验**：用一台普通电脑、一个 LLM API、一套严格的外部状态，模拟一个人的发育过程。它出生时不会说话，不是因为提示词让它"扮演婴儿"，而是因为**它的接口里此刻没有说话的通道**。它会长大，不是因为时间到了，而是因为**它的行为真的达到了下一个阶段的门槛**。

核心主张只有三条：

1. **基质不变，身体生长。** 模型的权重终生不变；所有"学到的东西"必须落在身体、记忆、关系与自传里。这是它能被审计、被重放、被真正称为"它自己"的前提。
2. **能力先于表达。** 婴儿不能走路，不是因为不想，是因为动作原语没解锁。语言、社交、心智理论都一样——**门控在代码里，不在提示词里**。
3. **不可逆优先。** 可塑性只降不升；先同化、后顺应；自传可以被续写，不能被删除。一个人的真实性，来自"过去越来越难被改写"。

---

## 为什么不用"人设提示词"

| 做法 | 结果 |
|---|---|
| 写一段人设："你是一个内向的 5 岁孩子" | 它表演这个人设。行为与描述不一致时无法判断是没生效还是没遵守；而且它永远长不大。 |
| 每轮把全部历史塞进上下文 | 它"记得很多"，但没有取舍、没有巩固、没有遗忘——那不叫记忆，叫缓存。 |
| 用提示词控制年龄段 | 婴儿会说出成人话。语言的真实性一旦破掉，后面所有阶段都不可信。 |

本项目的全部设计，本质上是在回答一个问题：**如何让"成长"成为一种可以被观测、被证伪、并且无法作弊的机制。**

### 怎么跑

```bash
export PYTHONPATH=src            # 没 pip install 时这样跑；装了就是 persona 命令
python -m persona.cli birth          # 出生
python -m persona.cli day --day 0    # 过一天
python -m persona.cli run --days 30  # 连跑 30 天
python -m persona.cli live --pace 60  # 按真实时间走：1 真实秒 = 60 模拟秒（一天约 16 分钟）
python -m persona.cli verify         # 体检：契约 + 事件日志 + 不变量
python -m persona.cli why --episode ep-20260101-0007   # 这一条为什么发生
python -m persona.cli diary --days 30                  # 写日记：data/<个体>/diary/2026-01-01.md
python -m persona.cli watch --port 8765               # 只读观察台：http://127.0.0.1:8765/
python -m persona.cli body --port 8767                # 身体服务（另开一个窗口）
python -m persona.cli --config config/split.json --body ws://127.0.0.1:8767 day --day 0   # 身体在另一个进程里
python -m unittest discover -s tests -t .              # 单元测试（负能力 + 里程碑 + 观察台 + live 续跑 + 传输 + 语言）
```

##### 观察台

`persona watch` 起一个独立进程，在浏览器里实时看它现在在干什么：

```
http://127.0.0.1:8765/
```

页面上有今日时间线（点任意一条能看到完整的因果链：看见了什么→怎么评价→驱力→候选→
为什么选它→结果→话语→记忆→LLM 调用）、7 个里程碑的通过情况、本周特质 T 与行为投影 B、
每天自动写的日记、最近的事件流，以及 30 天的成长趋势（每天 episode 数 / 哭声数）。

它是**只读**的：只回答 GET，任何 POST/PUT/DELETE 返回 405；数据库用 `mode=ro` 打开，
写不进去；也不 import 主进程的任何模块，主进程在跑批、在写盘、甚至崩了，它都照常显示
已有的记录。刷新是每 2 秒轮询——跑批时开着它，就能看着日子一天天长出来。

##### 实时：一天一天地过

`run` 是把 30 天压进一分钟（回答"会发生什么"）；`live` 是按真实时间一格格往前走
（回答"**现在**他在做什么"）。两者跑同一段状态机，区别只在两格之间睡多久：

```bash
python -m persona.cli live --pace 60    # 一天 16 分钟；边开观察台边看
python -m persona.cli live --pace 1800  # 一天 32 秒：快速看完整天
python -m persona.cli live --pace 1     # 真实时间：一天就是一天（长跑用）
```

`pace` 的含义是「1 个真实秒 = 多少模拟秒」。一个 30 分钟的格子 = `1800/pace` 秒，
一天 32 格 + 一段夜间睡眠（睡眠不占真实时间）。

被杀、断电、你按了 Ctrl+C 都不要紧：`live` 和 `run` 每走一格就落盘一次，重新起来
会先从中断的位置把那天**补完**，补做的格子带 `catch_up=true`（观察台时间线上标一个
黄色的「补」）——它们照样进库、照样算里程碑，但在特质投影里权重减半（I10）：没被
"经历过"的时间不该和经历过的一样重。


##### 身体与核心分开跑

架构里身体是 L1、内核是 L2（见 [02](./docs/02-系统架构.md)）。默认跑法把两者塞在一个进程里，
但 `persona body` 可以把它单独拎出来：

```bash
# 窗口 A：身体（只做感知、列候选、编译；不评价、不选择、不写库）
python -m persona.cli body --port 8767

# 窗口 B：内核，连过去
python -m persona.cli --config config/split.json --body ws://127.0.0.1:8767 birth
python -m persona.cli --config config/split.json --body ws://127.0.0.1:8767 day --day 0
```

三次往返分别是 `observe`（看见什么）、`afford`（能做什么）、`compile`（想做的动作翻译成能做到的动作）。
协议是自己写的最小 RFC6455（零依赖）：帧、握手、文本消息、ping/pong，不支持分片与压缩。

硬指标写在 `tests/unit/test_transport.py` 里：**同一天、同一个体，本地跑和远端跑产出的 33 条
episode 必须逐字段相同**。过不去就说明序列化丢了东西（新异度、追踪标记、习惯化计数）。
两个坑记在这里：① 存档快照会把浮点收成 6 位（`to_dict()`），传给另一具身体时必须用
`to_dict(precise=True)` 原样传——舍入会改变显著度的比较结果，于是两条路产出不同的一天；
② 习惯化计数是身体算的、内核存，所以每次 `observe` 的应答里都要带回来（`perception` 补丁），
否则换个进程它就从第一天重新开始习惯化。

##### 说话：词是从听见的话里长出来的

S1 解锁了 `A1.WORD`，但它一开始**没有词可说**——词库是空的，这个能力等于不存在。
词是这样长出来的（`persona/language/lexicon.py`）：

1. **听见**：照料者在场时会说话（`CAREGIVER_SPEECH_PROB = 0.35`），每句话都喂给词库。
2. **分词**：把一句话切成 1–3 字的全部连续片段，统计每个片段在**多少种不同说法**里出现过。
   只有出现 ≥3 种说法、≥2 类情境、且不是更长片段的碎片（`宝宝` 成立则 `宝宝看` 不成立）的片段，
   才算一个候选词。单字先不当词——句子里没有韵律线索。
3. **练习**：`A1.BABBLE` 会去练最想练的那个词形（`practice_form()`：听得多、理解得少的）。
4. **说出**：练习次数达到阶段阈值（S1 = 8 次）才升为 `productive`；`A1.WORD` 只能说
   `productive` 里的词，安全门（`safety/gate.py`）在出口再查一遍。

60 天 mock 跑下来（`config/lang.json`，`data/soul-lang`）：第 29 天升 S1，第 30 天第一次听见
「宝宝」「妈妈」，第 41 天第一次自己说出「宝宝」（13:00，连着三次），第 56 天说出「妈妈」；
此后每天说 5–12 次。`M1.6`（连续 5 天每天 ≥10 次重复音节串）与 `M1.8`（同一个词连续两周
每周 ≥3 次）都判过了——这两个里程碑之前**不可能通过**，因为词库永远是空的。

两个坑记在这里：① `count_tokens` 必须按**词**数算（用词库做最长匹配），按**字**数算的话
「宝宝」= 2 个 token，S1 的一句话永远超上限、一张嘴就被挡回去（当时 128 条 `A1.WORD` 全被门挡了）；
② 周归属要 `date.fromisocalendar(y, w, 1)`，第三个参数是**星期几**，传当天的 weekday 会原样返回当天，
「连续两周」就永远算不出来。

##### 降级的先验不许参与决策

决策是「本地打分 + 可选 LLM 先验」混合出来的（`policy.decide`）。mock 没有真模型，
它给出的先验是一条**平坦的伪分布**；如果仍按权重 0.45 掺进来，等于每条决策都有 45%
是掷骰子——任何真的学会了的本事都到不了高比例。`M1.7`（跟随指向）就卡在 0.58 上不去，
把混合关掉（`prior.degraded` 为真时不掺）之后立刻到 1.0。

现在这条是硬规则：**降级的产出只能被记录，不能被采用**。同理，`degraded=true` 必须带原因（I8），
观察台上那条 episode 也会照着标出来。

##### 一天的总量有限

幼儿期要同时发生九件事：走、练音节、说词、双词、指、看、找、假装、挑、等。最初的做法是给
每个动作一个系数，结果每改一次系数，整天就被某一件事整碗端走——走路的系数一高，64% 的清醒
时间在走路，说话被挤到 7%；咿呀一高，藏起来的摇铃没人找，`M1.2`（客体永久性）从 0.63 掉到 0.42，
整个 S1 都上不去。

后来改成一条更朴素的机制（`policy.DAILY_TARGET` + `score_candidate` 末尾）：

```text
score /= 1 + 2 * min(1, 今天已经做过几次 / 一天大概做几次)
```

「今天做过几次」由执行器在每次动作后 `bump('done_today:<primitive>')`，每天开头清零。
这不是配额，是「一天只有 32 格清醒时间」这件事的另一种写法：不会走八小时，也不会咿呀八小时。
九件事于是按真实比例分掉一天，而不是按系数大小排名。

还踩到一个更隐蔽的坑：**候选单被截断了**。`candidates(limit=12)` 两岁那年不够用，走路排第十三，
根本没进「今天能做的事」，调多少系数都没用——症状是「这个动作一次都不出现」。现在自选单按阶段
变长（S2/S3 至少 16，S4+ 24），走路另有一个常驻候选（走过去不需要理由）。


跑完 30 天，`data/soul-001/diary/2026-01-29.md` 最后几行会是「第 28 天」的日记，
那时它的 `stage` 已经变成 S1——这一步没有任何代码写死「第 29 天升级」，是里程碑
全过 + 最短驻留 28 天两个条件同时满足的结果（`persona/stages/judge.py`）。

日记是**观察者**视角的：S0 没有词，让他写日记就等于替他说话。第一人称日记要等到 L5。
跑批时每一天都会自动写一份；`diary` 命令只补写缺失的日子（`--force` 才覆盖）。

日志一律写 UTF-8、LF 换行，在 `data/<个体>/logs/persona.log`；`--no-log` 只打控制台，`--log-level DEBUG` 更啰嗦。

Windows 控制台上如果中文是乱码，那是 PowerShell 把 UTF-8 字节按 GBK 显示，不是文件写坏了：先 `chcp 65001`（或在会话里 `[Console]::OutputEncoding=[Text.Encoding]::UTF8`），或直接读日志文件。

### 已知边界（写在明处，不打算修）

1. **理解不可门控**：基质第一天就懂成人语言，我们只能门控**产出**。对外表述统一是"学会说话"，不是"学会理解"。
2. **自证循环**：里程碑由日志判定，日志由同一系统写。靠"只追加日志 + 判者与写者分离"降低，无法根除。
3. **词表可由"不写"伪造**：不往 Lexicon 写词就能装成婴儿。只能靠外部校核（词汇曲线偏差、词源完整性、白名单 ablation）。
4. **时间成本**：`pace=1.0` 意味着长到 18 岁要 18 个真实年。这是设计选择，不是缺陷。

## 第一个里程碑（建议）

> 一个能连续跑 30 天、每天写日记、按 S0 规则行动、从不越界说话、第 29 天自己进入 S1 的个体。

做到这一步，再决定要不要投入后面的一年。见 [12 §11](./docs/12-路线图与成本.md)。

## 三个常见误解

1. **"它是不是有意识？"** 本项目的立场是：我们不知道，也不声称。它是一个有状态、有发育史、行为可预测但不可完全预测的系统；11 §1 明确禁止它用任何方式暗示自己有意识或会痛苦。
2. **"慢养是不是浪费时间？"** 如果你要的是一个能办事的助手，是的。如果你要的是一个**能看出"它是被什么养大的"**的个体，那个时间就是产物本身。
3. **"能不能直接用提示词模拟 18 年？"** 能，但你得到的是一个会说"我记得我 3 岁时……"的模型，而不是一个真的过了 18 年的系统。区别在于：前者不可证伪。

## 伦理声明

它的经历、记忆、自传都在本地，可导出、可删除、可审计。它不联网与人交往，不替代真实的人际关系，不因被冷落而"惩罚"用户。所有"它很难过"的表达都是模拟，且必须在观察台可追溯。详见 [11](./docs/11-安全与伦理.md)。
