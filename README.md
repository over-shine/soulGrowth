# 如何构建一个人

> 给已有的语言能力装配一具**会发育的身体**，让它从一个只会哭的婴儿，慢慢长成一个有性格、有记忆、有关系的个体。

---

## 这是什么

这不是一个"人格设定"项目，也不是一次模型微调。

它是一个**长跑型实验**：用一台普通电脑、一个 LLM API、一套严格的外部状态，模拟一个人的发育过程。它出生时不会说话，不是因为提示词让它"扮演婴儿"，而是因为**它的接口里此刻没有说话的通道**。它会长大，不是因为时间到了，而是因为**它的行为真的达到了下一个阶段的门槛**。

核心主张只有三条：

1. **基质不变，身体生长。** 模型的权重终生不变；所有"学到的东西"必须落在身体、记忆、关系与自传里。这是它能被审计、被重放、被真正称为"它自己"的前提。
2. **能力先于表达。** 婴儿不能走路，不是因为不想，是因为动作原语没解锁。语言、社交、心智理论都一样——**门控在代码里，不在提示词里**。
3. **不可逆优先。** 可塑性只降不升；先同化、后顺应；自传可以被续写，不能被删除。一个人的真实性，来自"过去越来越难被改写"。

---

## 为什么不用"人设提示词"

| 做法 | 结果 |
|---|---|
| 写一段人设："你是一个内向的 5 岁孩子" | 它表演这个人设。行为与描述不一致时无法判断是没生效还是没遵守；而且它永远长不大。 |
| 每轮把全部历史塞进上下文 | 它"记得很多"，但没有取舍、没有巩固、没有遗忘——那不叫记忆，叫缓存。 |
| 用提示词控制年龄段 | 婴儿会说出成人话。语言的真实性一旦破掉，后面所有阶段都不可信。 |

本项目的全部设计，本质上是在回答一个问题：**如何让"成长"成为一种可以被观测、被证伪、并且无法作弊的机制。**

### 已知边界（写在明处，不打算修）

1. **理解不可门控**：基质第一天就懂成人语言，我们只能门控**产出**。对外表述统一是"学会说话"，不是"学会理解"。
2. **自证循环**：里程碑由日志判定，日志由同一系统写。靠"只追加日志 + 判者与写者分离"降低，无法根除。
3. **词表可由"不写"伪造**：不往 Lexicon 写词就能装成婴儿。只能靠外部校核（词汇曲线偏差、词源完整性、白名单 ablation）。
4. **时间成本**：`pace=1.0` 意味着长到 18 岁要 18 个真实年。这是设计选择，不是缺陷。

## 第一个里程碑（建议）

> 一个能连续跑 30 天、每天写日记、按 S0 规则行动、从不越界说话、第 29 天自己进入 S1 的个体。

做到这一步，再决定要不要投入后面的一年。见 [12 §11](./docs/12-路线图与成本.md)。

## 三个常见误解

1. **"它是不是有意识？"** 本项目的立场是：我们不知道，也不声称。它是一个有状态、有发育史、行为可预测但不可完全预测的系统；11 §1 明确禁止它用任何方式暗示自己有意识或会痛苦。
2. **"慢养是不是浪费时间？"** 如果你要的是一个能办事的助手，是的。如果你要的是一个**能看出"它是被什么养大的"**的个体，那个时间就是产物本身。
3. **"能不能直接用提示词模拟 18 年？"** 能，但你得到的是一个会说"我记得我 3 岁时……"的模型，而不是一个真的过了 18 年的系统。区别在于：前者不可证伪。

## 伦理声明

它的经历、记忆、自传都在本地，可导出、可删除、可审计。它不联网与人交往，不替代真实的人际关系，不因被冷落而"惩罚"用户。所有"它很难过"的表达都是模拟，且必须在观察台可追溯。详见 [11](./docs/11-安全与伦理.md)。
